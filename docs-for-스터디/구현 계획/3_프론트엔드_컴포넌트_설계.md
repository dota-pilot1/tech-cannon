# 프론트엔드 컴포넌트 설계 (v3.0)

## 📐 전체 구조

### 페이지 라우팅
```
/study          → StudyHomePage  (페이지1: 카테고리별 게시글 카드 그리드)
/study?postId=N → StudyViewPage  (페이지2: 사이드바 + 문서 본문)
/study?mode=new → StudyViewPage  (페이지2: 사이드바 + 새 글 작성)
```

### 컴포넌트 계층
```
StudyPage  (라우트 컨테이너 - postId 쿼리 파라미터로 페이지 분기)
├── StudyHomePage          (페이지1: 홈 그리드)
│   └── StudyPostCard      (게시글 카드)
└── StudyViewPage          (페이지2: 문서 뷰)
    ├── StudySidebar       (좌측: 카테고리 트리 + 게시글 목록)
    └── StudyPostDetail    (우측: 본문 뷰어 / 에디터)
        └── StudyCommentList (댓글)
```

## 🧩 컴포넌트 상세 설계

### 1. StudyPage (라우트 컨테이너)

**파일**: `parantier-front/src/pages/study/StudyPage.tsx`

**역할**:
- URL 쿼리 파라미터(`postId`, `mode`)를 읽어 페이지1/페이지2 분기
- `useNavigate`로 페이지 간 이동 처리

**상태 분기 로직**:
```typescript
// postId가 있거나 mode=new 이면 → 페이지2
// 그 외 → 페이지1
const searchParams = new URLSearchParams(window.location.search)
const postId = searchParams.get('postId')   // → 페이지2 (문서 뷰)
const mode   = searchParams.get('mode')     // 'new' → 페이지2 (새 글 작성)
```

**구현 예시**:
```tsx
export function StudyPage() {
  const [postId, setPostId] = useState<number | null>(() => {
    const p = new URLSearchParams(window.location.search).get('postId')
    return p ? Number(p) : null
  })
  const [isNewMode, setIsNewMode] = useState(() => {
    return new URLSearchParams(window.location.search).get('mode') === 'new'
  })
  const [newCategoryId, setNewCategoryId] = useState<number | null>(null)

  const navigate = useNavigate()

  const goToPost = (id: number) => {
    setPostId(id)
    setIsNewMode(false)
    navigate({ to: '/study', search: { postId: String(id) } })
  }

  const goToNew = (categoryId: number) => {
    setNewCategoryId(categoryId)
    setIsNewMode(true)
    setPostId(null)
    navigate({ to: '/study', search: { mode: 'new' } })
  }

  const goHome = () => {
    setPostId(null)
    setIsNewMode(false)
    navigate({ to: '/study' })
  }

  const isViewPage = !!postId || isNewMode

  if (isViewPage) {
    return (
      <StudyViewPage
        postId={postId}
        isNewMode={isNewMode}
        newCategoryId={newCategoryId}
        onSelectPost={goToPost}
        onGoHome={goHome}
      />
    )
  }

  return (
    <StudyHomePage
      onSelectPost={goToPost}
      onNewPost={goToNew}
    />
  )
}
```

```tsx
export function StudyHomePage({ onSelectPost, onNewPost }: StudyHomePageProps) {
  const [searchQuery, setSearchQuery] = useState('')
  const [inputValue, setInputValue] = useState('')
  const { data: categories = [] } = useStudyCategoryTree()
  // 카테고리별로 게시글을 각각 조회
```

### 3. StudyCategorySection (카테고리 섹션)

**파일**: `parantier-front/src/features/study/components/StudyCategorySection.tsx`

**역할**:
- 카테고리 이름 + 구분선 헤더
- 해당 카테고리 게시글 카드 가로 나열 (최대 4개, 이후 "더보기")
- 게시글 없으면 "첫 게시글을 작성해보세요" 빈 상태

**구현 예시**:
```tsx
interface StudyCategorySectionProps {
  category: StudyCategory
  searchQuery: string
  onSelectPost: (id: number) => void
  onNewPost: (categoryId: number) => void
}

export function StudyCategorySection({
  category,
  searchQuery,
  onSelectPost,
  onNewPost,
}: StudyCategorySectionProps) {
  const { data: posts = [], isLoading } = useStudyPosts(category.id, searchQuery)

  return (
    <section>
      {/* 카테고리 헤더 */}
      <div className="flex items-center gap-3 mb-3">
        <h2 className="text-base font-semibold text-foreground whitespace-nowrap">
          {category.icon} {category.name}
        </h2>
        <div className="flex-1 h-px bg-border" />
        <button
          onClick={() => onNewPost(category.id)}
          className="text-xs text-muted-foreground hover:text-primary flex items-center gap-1 shrink-0"
        >
          <Plus className="w-3 h-3" />
          글쓰기
        </button>
      </div>

      {/* 카드 그리드 */}
      {isLoading ? (
        <div className="flex gap-3">
          {[1, 2, 3].map((i) => (
            <div key={i} className="w-52 h-28 rounded-xl bg-muted/40 animate-pulse" />
          ))}
        </div>
      ) : posts.length === 0 ? (
        <div className="py-4 text-sm text-muted-foreground">
          아직 게시글이 없습니다.{' '}
          <button onClick={() => onNewPost(category.id)} className="text-primary hover:underline">
            첫 글을 작성해보세요
          </button>
        </div>
      ) : (
        <div className="flex flex-wrap gap-3">
          {posts.slice(0, 4).map((post) => (
            <StudyPostCard
              key={post.id}
              post={post}
              onClick={() => onSelectPost(post.id)}
            />
          ))}
          {posts.length > 4 && (
            <button
              onClick={() => onSelectPost(posts[4].id)}
              className="w-40 h-[108px] rounded-xl border-2 border-dashed border-border
                         flex flex-col items-center justify-center gap-1
                         text-muted-foreground hover:border-primary hover:text-primary transition-colors"
            >
              <ChevronRight className="w-5 h-5" />
              <span className="text-xs">+{posts.length - 4}개 더보기</span>
            </button>
          )}
        </div>
      )}
    </section>
  )
}
```

### 4. StudyPostCard (게시글 카드)

**파일**: `parantier-front/src/features/study/components/StudyPostCard.tsx`

**역할**:
- 게시글 요약 카드 (제목, 작성자, 날짜, 조회수/댓글/좋아요)
- 고정글 📌 배지
- hover 시 그림자 효과

**구현 예시**:
```tsx
interface StudyPostCardProps {
  post: StudyPost
  onClick: () => void
}

export function StudyPostCard({ post, onClick }: StudyPostCardProps) {
  const relativeDate = (dateStr: string) => {
    const diff = Date.now() - new Date(dateStr).getTime()
    const days = Math.floor(diff / 86400000)
    if (days === 0) return '오늘'
    if (days < 7) return `${days}일 전`
    if (days < 30) return `${Math.floor(days / 7)}주 전`
    return `${Math.floor(days / 30)}개월 전`
  }

  return (
    <button
      onClick={onClick}
      className="w-52 h-[108px] rounded-xl border bg-card text-left p-3
                 flex flex-col justify-between
                 hover:shadow-md hover:border-primary/40 transition-all"
    >
      <div>
        <div className="flex items-start gap-1 mb-1">
          {post.isPinned && <span className="text-xs">📌</span>}
          <p className="text-sm font-medium text-card-foreground line-clamp-2 leading-snug">
            {post.title}
          </p>
        </div>
        <p className="text-xs text-muted-foreground">
          {post.authorName} · {relativeDate(post.createdAt)}
        </p>
      </div>
      <div className="flex items-center gap-2 text-xs text-muted-foreground">
        <span>👁 {post.viewCount}</span>
        <span>💬 {post.commentCount}</span>
        <span>👍 {post.likeCount}</span>
      </div>
    </button>
  )
}
```

```tsx
interface StudyViewPageProps {
  postId: number | null
  isNewMode: boolean
  newCategoryId: number | null
  onSelectPost: (id: number) => void
  onGoHome: () => void
}

export function StudyViewPage({
  postId,
  isNewMode,
  newCategoryId,
  onSelectPost,
  onGoHome,
}: StudyViewPageProps) {
  const [isEditing, setIsEditing] = useState(isNewMode)
  const [editingCategoryId, setEditingCategoryId] = useState<number | null>(newCategoryId)
```

### 6. StudySidebar (페이지2 좌측 사이드바)

**파일**: `parantier-front/src/features/study/components/StudySidebar.tsx`

**역할**:
- "← 목록으로" 버튼 (페이지1로 복귀)
- 카테고리 아코디언 트리
- 카테고리 클릭 시 해당 게시글 목록 펼침
- 현재 선택된 게시글 하이라이트
- 각 카테고리에 "+ 글쓰기" 버튼

**Props**:
```typescript
interface StudySidebarProps {
  selectedPostId: number | null
  onSelectPost: (id: number) => void
  onGoHome: () => void
  onNewPost: (categoryId: number) => void
}
```

**구현 예시**:
```tsx
export function StudySidebar({
  selectedPostId,
  onSelectPost,
  onGoHome,
  onNewPost,
}: StudySidebarProps) {
  const { data: categories = [] } = useStudyCategoryTree()
  const [expandedIds, setExpandedIds] = useState<Set<number>>(new Set())

  // 현재 선택된 게시글의 카테고리 자동 펼침
  const { data: currentPost } = useStudyPost(selectedPostId)
  useEffect(() => {
    if (currentPost?.categoryId) {
      setExpandedIds((prev) => new Set([...prev, currentPost.categoryId]))
    }
  }, [currentPost?.categoryId])

  return (
    <aside className="w-60 border-r bg-background flex flex-col shrink-0 overflow-hidden">
      {/* 목록으로 버튼 */}
      <button
        onClick={onGoHome}
        className="flex items-center gap-2 px-4 py-3 text-sm text-muted-foreground
                   hover:text-foreground hover:bg-muted/50 border-b transition-colors"
      >
        <ArrowLeft className="w-4 h-4" />
        목록으로
      </button>

      {/* 카테고리 트리 */}
      <div className="flex-1 overflow-y-auto py-1">
        {categories.map((category) => (
          <StudySidebarCategory
            key={category.id}
            category={category}
            isExpanded={expandedIds.has(category.id)}
            selectedPostId={selectedPostId}
            onToggle={() => {
              setExpandedIds((prev) => {
                const next = new Set(prev)
                next.has(category.id) ? next.delete(category.id) : next.add(category.id)
                return next
              })
            }}
            onSelectPost={onSelectPost}
            onNewPost={onNewPost}
          />
        ))}
      </div>
    </aside>
  )
}
```

```tsx
export function StudySidebarCategory({
  category,
  isExpanded,
  selectedPostId,
  onToggle,
  onSelectPost,
  onNewPost,
}: StudySidebarCategoryProps) {
  const { data: posts = [] } = useStudyPosts(isExpanded ? category.id : null)

  return (
    <div>
      {/* 카테고리 행 */}
      <div
        className="group flex items-center gap-1.5 px-3 py-1.5 text-sm cursor-pointer
                   hover:bg-muted/50 text-foreground"
        onClick={onToggle}
      >
        <span className="text-[10px] text-muted-foreground w-3 shrink-0">
          {isExpanded ? '▼' : '▶'}
        </span>
        <span className="shrink-0">{category.icon || '📁'}</span>
        <span className="flex-1 truncate font-medium">{category.name}</span>
        <button
          onClick={(e) => { e.stopPropagation(); onNewPost(category.id) }}
          className="opacity-0 group-hover:opacity-100 text-muted-foreground hover:text-primary"
        >
          <Plus className="w-3 h-3" />
        </button>
      </div>

      {/* 게시글 목록 (펼쳐진 상태) */}
      {isExpanded && (
        <div>
          {posts.map((post) => (
            <div
              key={post.id}
              onClick={() => onSelectPost(post.id)}
              className={cn(
                'flex items-center gap-2 pl-8 pr-3 py-1 text-xs cursor-pointer transition-colors',
                selectedPostId === post.id
                  ? 'bg-primary/10 text-primary font-medium'
                  : 'text-muted-foreground hover:text-foreground hover:bg-muted/40'
              )}
            >
              <span className="shrink-0">📄</span>
              <span className="truncate">{post.title}</span>
            </div>
          ))}
        </div>
      )}
    </div>
  )
}
```
