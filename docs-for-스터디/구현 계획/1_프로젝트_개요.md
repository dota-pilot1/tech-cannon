# 스터디 기능 구현 계획

## 📌 프로젝트 개요

### 목적
- 팀원들이 학습한 내용을 공유하고 토론할 수 있는 스터디 포럼 구현
- 카테고리 기반으로 주제를 분류하여 체계적인 지식 관리
- 좋아요 / 댓글 / 조회수를 통한 인터랙티브한 학습 문화 형성

### 네이밍 규칙
| 구분 | 이름 |
|---|---|
| 헤더 메뉴명 | `스터디` |
| 백엔드 패키지 | `com.mapo.palantier.study` |
| API 경로 | `/api/study/...` |
| DB 테이블 | `study_categories`, `study_posts`, `study_comments`, `study_likes` |
| 프론트 라우트 | `/study` |
| 프론트 폴더 | `src/features/study/`, `src/pages/study/` |

## 🎯 핵심 기능

### 1. 카테고리 시스템
- **대분류 (Level 1)**: React, Java, DB, DevOps, WebSocket, Redis, Kafka, Architecture, Security, Figma, SpringBoot, React Native, Pilot
- 헤더 노트 관리 메뉴의 카테고리와 동일한 구조
- 관리자만 카테고리 생성/수정/삭제 가능

### 2. 3단 레이아웃
```
┌──────────────┬───────────────────┬─────────────────────────┐
│  좌측 (240px)│  중앙 (flex 40%)  │  우측 (flex 60%)        │
├──────────────┼───────────────────┼─────────────────────────┤
│ 카테고리 트리│  게시글 목록       │  게시글 본문 & 댓글      │
│              │                   │                         │
│ ▼ React      │ 📌 React 19 기능  │ # React 19 주요 업데이트│
│   Java       │ 📄 TanStack Query │                         │
│   DB         │ 📄 useOptimistic  │ ## 1. Server Components │
│   DevOps     │                   │ ...                     │
│   WebSocket  │  + 새 게시글      │ 👍 12  💬 3  👁 42      │
│   ...        │                   │ [댓글 작성]             │
└──────────────┴───────────────────┴─────────────────────────┘
```

### 3. 게시글 (study_posts)
- 제목 + 본문 (Lexical 리치 에디터)
- 작성자, 작성일, 조회수 표시
- 상단 고정 기능 (관리자)
- 공개/비공개 설정

### 4. 댓글 (study_comments)
- 게시글당 댓글 작성/수정/삭제
- 작성자만 수정/삭제 가능
- 댓글 수 표시

### 5. 좋아요 (study_likes)
- 게시글 좋아요 토글
- 좋아요 수 표시
- 본인 좋아요 여부 표시

### 6. 검색
- 제목 + 본문 키워드 검색
- 카테고리 필터링

## 🎨 UI/UX 설계

### 화면 흐름
1. 사용자가 헤더 "스터디" 메뉴 클릭 → `/study`
2. 좌측 카테고리 트리 표시
3. 카테고리 선택 → 중앙에 게시글 목록 표시
4. 게시글 선택 → 우측에 본문 + 댓글 표시
5. 편집 버튼 → Lexical 에디터로 전환
6. 저장 → 서버 업데이트

### 주요 인터랙션
- 카테고리 클릭 → 해당 게시글 목록 로드
- 게시글 클릭 → 본문 표시 (조회수 +1)
- 편집 버튼 → Lexical 에디터 모드 전환
- 좋아요 버튼 → 토글
- 댓글 작성 → 실시간 목록 업데이트
- 새 게시글 버튼 → 중앙 상단 "+" 클릭

상세 UI 흐름은 `uiux 흐름 mmd/` 폴더 참조

## 📦 기술 스택

### Frontend
- React + TypeScript
- TanStack Router (라우팅: `/study`)
- TanStack Query (데이터 페칭)
- Tailwind CSS + shadcn/ui
- **Lexical 에디터** (이미 프로젝트에 적용됨 → `src/shared/ui/lexical/`)

### Backend
- Spring Boot 3 + MyBatis
- PostgreSQL
- AWS S3 (이미지 첨부파일)
- JWT 인증
