# ag-grid 수정 기능 구현 가이드

> 기준 구현체: `parantier-front/src/pages/work/WorkPage.tsx`

---

## 1. 핵심 개념: 수정 감지 방식

이 프로젝트의 ag-grid 수정 저장 패턴은 다음과 같습니다.

```
셀 편집 완료 (엔터 / 탭 / 클릭아웃)
    → onCellValueChanged 이벤트 발동
    → modifiedRowIds Set에 row.id 추가
    → 해당 행 노란색 하이라이트
    → 저장 버튼 클릭 시 → handleSaveModified()
```

**체크박스로 저장 대상을 선택하는 방식은 사용하지 않습니다.**
ag-grid에서 체크박스는 "삭제/백업 등 일괄 처리 대상 선택"용이고,
저장 대상 추적은 `onCellValueChanged`로 하는 것이 공식 권장 패턴입니다.

---

## 2. 수정 감지: `onCellValueChanged`

```tsx
const onCellValueChanged = (params: CellValueChangedEvent<Work>) => {
  const { data, newValue, oldValue } = params;

  // 값이 실제로 바뀐 경우만 처리
  if (newValue === oldValue) return;

  // 수정된 행 ID를 Set에 추가 (중복 없음)
  setModifiedRowIds((prev) => new Set(prev).add(data.id));
};
```

- `modifiedRowIds`는 `Set<number>` 타입
- 같은 행을 여러 번 수정해도 Set이므로 중복 없음
- 행 ID가 음수(`< 0`)이면 신규 행, 양수(`> 0`)이면 기존 행 수정

---

## 3. 수정된 행 시각화: `rowClassRules`

```tsx
const rowClassRules = {
  'bg-yellow-50': (params) => modifiedRowIds.has(params.data?.id),  // 수정된 행
  'bg-blue-50': (params) => params.data?.id === selectedWorkId,      // 선택된 행
};
```

## 4. 저장 처리: `handleSaveModified`

```tsx
const handleSaveModified = async () => {
  if (modifiedRowIds.size === 0) {
    toast.info("수정된 항목이 없습니다.");
    return;
  }

  // 1. 수정된 행 데이터 수집
  const modifiedRows: Work[] = [];
  gridRef.current?.api.forEachNode((node) => {
    if (modifiedRowIds.has(node.data.id)) {
      modifiedRows.push(node.data);
    }
  });

  // 2. 신규 / 수정 분리 (id 음수 = 신규)
  const newRows    = modifiedRows.filter((r) => r.id < 0);
  const updatedRows = modifiedRows.filter((r) => r.id > 0);

  // 3. 유효성 검사 (필수 필드 누락 체크)
  // ... (필수값 누락 시 confirm 다이얼로그)

  // 4. API 호출
  for (const row of newRows)     await createWorkSilent({ ... });
  for (const row of updatedRows) await updateWorkSilent({ id: row.id, request: { ... } });

  // 5. 신규 행 임시 제거 (서버에서 새 ID로 재조회됨)
  if (newRows.length > 0) {
    gridRef.current?.api.applyTransaction({ remove: newRows });
  }

  // 6. 상태 초기화 + 쿼리 무효화
  setModifiedRowIds(new Set());
  await queryClient.invalidateQueries({ queryKey: ["works"] });
};
```

## 6. 체크박스 + `onRowClicked` 충돌 해결

### 문제

`onRowClicked`가 있으면 체크박스 클릭 시에도 이벤트가 같이 발동되어
행 선택 상태가 꼬일 수 있음.

### 해결

```tsx
const onRowClicked = (event: RowClickedEvent<Work>) => {
  if (!event.data) return;

  // 체크박스 컬럼 클릭 시 무시
  const target = event.event?.target as HTMLElement;
  if (target?.closest('.ag-selection-checkbox')) return;

  setSelectedWorkId(event.data.id);
};
```

### ag-grid 설정

```tsx
<AgGridReact
  rowSelection="multiple"
  suppressRowClickSelection={true}   // 행 클릭으로 선택 안 됨 (체크박스로만 선택)
  onRowClicked={onRowClicked}
  onCellValueChanged={onCellValueChanged}
/>
```

### 체크박스 컬럼 정의

```tsx
{
  headerName: "",
  width: 52,
  maxWidth: 52,
  minWidth: 52,
  checkboxSelection: true,        // 행 체크박스
  headerCheckboxSelection: true,  // 헤더 전체 선택 체크박스
  suppressMovable: true,
  suppressSizeToFit: true,
  resizable: false,
}
```

## 7. 체크박스의 올바른 용도

ag-grid에서 체크박스 선택은 **저장 대상 추적이 아니라** 아래 용도로 사용:

```tsx
// 선택된 행 삭제
const handleDeleteSelected = async () => {
  const selectedRows = gridRef.current?.api.getSelectedRows();
  // ...
};

// 선택된 행 백업(아카이브)
const handleArchive = async () => {
  const selectedNodes = gridRef.current?.api.getSelectedNodes();
  const ids = selectedNodes.map((n) => n.data?.id);
  // ...
};
```

## 8. 패턴 요약

| 기능 | 구현 방법 |
|------|-----------|
| 수정 감지 | `onCellValueChanged` → `modifiedRowIds` Set에 추가 |
| 수정 시각화 | `rowClassRules`로 노란색 하이라이트 |
| 신규 행 | 음수 임시 ID로 생성 후 `applyTransaction({ add })` |
| 저장 | 저장 버튼 클릭 → `handleSaveModified()` |
| 체크박스 | 삭제/백업 등 일괄 처리 대상 선택용 |
| 체크박스 클릭 충돌 | `onRowClicked`에서 `.ag-selection-checkbox` 클릭 무시 |
