## 인증/인가

- JWT Bearer Token 방식
- Role: `ROLE_USER` (일반), `ROLE_ADMIN` (관리자)
- 공개 경로: `/api/auth/**`, `/api/menus/**`, `GET /api/**` (읽기는 공개)
- 인증 필요: POST/PUT/DELETE 대부분

## 로컬 개발 환경

### 백엔드 실행
```bash
cd parantier-api
./gradlew bootRun --args='--spring.profiles.active=local'
```
- `application-local.yml` 필요 (gitignore됨)
- Docker로 PostgreSQL 자동 실행 (compose.yaml)

### 프론트 실행
```bash
cd parantier-front
npm install
npm run dev
```
- 로컬 API: `http://localhost:8080`
