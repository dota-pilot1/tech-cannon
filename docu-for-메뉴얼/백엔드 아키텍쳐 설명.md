## 레이어 구조

각 도메인은 아래 레이어로 구성됩니다:

```
domain/
├── presentation/   # Controller (@RestController)
├── application/    # Service (@Service, @Transactional)
├── infrastructure/ # Mapper Interface (@Mapper - MyBatis)
├── domain/         # Entity/Domain 클래스
└── dto/            # Request/Response DTO
```

예시: `task` 도메인
```
task/
├── folder/
│   ├── presentation/TaskFolderController.java
│   ├── TaskFolderService.java
│   ├── TaskFolderMapper.java
│   └── TaskFolder.java (도메인)
├── post/
│   ├── presentation/TaskPostController.java
│   ├── TaskPostService.java
│   ├── TaskPostMapper.java
│   └── TaskPost.java
├── block/
│   ├── TaskBlockMapper.java
│   ├── TaskBlock.java
│   └── BlockType.java (enum: NOTE/MMD/FIGMA/FILE/DBTABLE/GITHUB)
├── comment/
└── dto/
    ├── TaskFolderDto.java
    ├── TaskPostDto.java
    └── TaskBlockDto.java
```

## MyBatis 설정

- XML Mapper 방식 사용
- Mapper 위치: `src/main/resources/mybatis/mapper/**/*.xml`
- camelCase 자동 변환: `map-underscore-to-camel-case: true`
- type-aliases-package: `com.mapo.palantier`

### Mapper XML 패턴
```xml
<mapper namespace="com.mapo.palantier.task.folder.TaskFolderMapper">
    <resultMap id="TaskFolderResultMap" type="com.mapo.palantier.task.folder.TaskFolder">
        ...
    </resultMap>
    <select id="findAll" resultMap="TaskFolderResultMap">...</select>
    <insert id="insert" useGeneratedKeys="true" keyProperty="id">...</insert>
    <update id="update">...</update>
    <update id="softDelete">...</update>
</mapper>
```

### Mapper Interface 패턴
```java
@Mapper
public interface TaskFolderMapper {
    List<TaskFolder> findAll();
    Optional<TaskFolder> findById(@Param("id") Long id);
    void insert(TaskFolder folder);
    void update(TaskFolder folder);
    void softDelete(@Param("id") Long id);
}
```

## DB 구조 패턴

### 폴더+게시글+블록 패턴 (task, wiki, subutai 등 공통)
```sql
-- 폴더 (계층 구조)
task_folders (id, parent_id, name, sort_order, created_by, deleted_at)

-- 게시글
task_posts (id, folder_id, title, author_id, deleted_at)

-- 블록 (컨텐츠 단위)
task_blocks (id, post_id, block_type, content, sort_order)
```

블록 타입 (BlockType enum):
- `NOTE`: 마크다운 텍스트
- `MMD`: Mermaid 다이어그램
- `FIGMA`: Figma 임베드 URL
- `FILE`: 파일 첨부 (JSON)
- `DBTABLE`: DB 테이블 정의 (JSON)
- `GITHUB`: GitHub 링크

### 카테고리+섹션+블록 패턴 (faq, backend, figma, subutai-faq 등)
```sql
-- 카테고리
faq_categories (id, name, icon, emoji, order_num, is_active)

-- 섹션 (카테고리 하위)
faq_sections (id, category_id, title, order_num, is_active)

-- 블록 (섹션 내 컨텐츠)
faq_blocks (id, section_id, block_type, content, sort_order)
```

## Security 설정

```java
// 공개 경로
/api/auth/**          → 로그인/회원가입
/api/menus/**         → 메뉴 목록 (동적 네비게이션)
GET /api/**           → 조회는 모두 공개
/ws/**                → WebSocket
/swagger-ui/**        → API 문서

// 인증 필요
POST/PUT/DELETE /api/** → JWT 필수

// 관리자 전용
/api/admin/**         → ROLE_ADMIN
@PreAuthorize("hasRole('ADMIN')")
```

### JWT 흐름
1. 클라이언트: `Authorization: Bearer <token>` 헤더
2. `JwtAuthenticationFilter`: 토큰 추출/검증
3. `SecurityContextHolder`에 Authentication 설정
4. Controller에서 `@AuthenticationPrincipal User user`로 주입

## Controller 패턴

```java
@Tag(name = "Task 폴더", description = "Task 폴더 관리 API")
@RestController
@RequestMapping("/api/tasks/folders")
@RequiredArgsConstructor
public class TaskFolderController {
    private final TaskFolderService taskFolderService;

    @GetMapping
    public ResponseEntity<List<TaskFolder>> getAllFolders() {
        return ResponseEntity.ok(taskFolderService.getAllFolders());
    }

    @PostMapping
    public ResponseEntity<Long> createFolder(
            @RequestBody TaskFolderDto dto,
            @AuthenticationPrincipal User user) {
        Long folderId = taskFolderService.createFolder(dto, user.getId());
        return ResponseEntity.ok(folderId);
    }
}
```
