## 공개/인증 경로 설정

```java
.authorizeHttpRequests(auth -> auth
    // 공개 (인증 불필요)
    .requestMatchers("/actuator/health/**").permitAll()
    .requestMatchers("/swagger-ui/**", "/v3/api-docs/**").permitAll()
    .requestMatchers("/api/auth/signup", "/api/auth/login", "/api/auth/check-email").permitAll()
    .requestMatchers("/api/menus/**").permitAll()   // 동적 메뉴 (비로그인도 조회)
    .requestMatchers("/ws/**").permitAll()           // WebSocket
    .requestMatchers("/api/chat/**").permitAll()
    .requestMatchers("/api/sql/**").permitAll()
    .requestMatchers(HttpMethod.GET, "/api/**").permitAll()  // 조회 전체 공개

    // 관리자 전용
    .requestMatchers("/api/admin/**").hasRole("ADMIN")

    // 나머지 POST/PUT/DELETE → 인증 필요
    .requestMatchers("/api/**").authenticated()
    .anyRequest().authenticated()
)
```

## JWT 필터 체인

```
요청
 │
 ▼
JwtAuthenticationFilter (OncePerRequestFilter)
 │  1. Authorization 헤더에서 Bearer 토큰 추출
 │  2. JwtTokenProvider.validateToken(token)
 │  3. 유효하면 email, role, userId 추출
 │  4. request.setAttribute("userId", userId)
 │  5. UsernamePasswordAuthenticationToken 생성
 │  6. SecurityContextHolder에 설정
 ▼
AuthorizationFilter
 │  경로별 권한 체크
 ▼
Controller
```

## JwtTokenProvider 주요 메서드

| 메서드 | 설명 |
|--------|------|
| `generateAccessToken(userId, email, role)` | 액세스 토큰 생성 (개인+조직 권한 포함) |
| `generateRefreshToken(email)` | 리프레시 토큰 생성 |
| `validateToken(token)` | 토큰 유효성 검증 |
| `validateAccessToken(token)` | 액세스 토큰 타입까지 검증 |
| `getEmailFromToken(token)` | 이메일 추출 |
| `getUserIdFromToken(token)` | userId 추출 |
| `getRoleFromToken(token)` | role 추출 |
| `getAuthoritiesFromToken(token)` | authorities 목록 추출 |

## @PreAuthorize 사용

```java
// 관리자 전용 API
@PreAuthorize("hasRole('ADMIN')")
@PostMapping("/categories")
public ResponseEntity<Void> createCategory(...) { ... }

// 인증된 사용자 (SecurityConfig 기본 설정으로 처리)
@PostMapping("/posts")
public ResponseEntity<Long> savePost(
    @RequestBody TaskPostDto dto,
    @AuthenticationPrincipal User user   // JWT에서 추출된 사용자
) { ... }
```
