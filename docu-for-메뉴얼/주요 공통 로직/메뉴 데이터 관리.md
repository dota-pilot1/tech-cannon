CREATE TABLE menus (
    id            BIGSERIAL PRIMARY KEY,
    name          VARCHAR(100) NOT NULL,
    path          VARCHAR(255),
    parent_id     BIGINT REFERENCES menus(id) ON DELETE CASCADE,
    menu_type     VARCHAR(20) NOT NULL,   -- HEADER / SUB / PAGE / CATEGORY
    order_num     INTEGER DEFAULT 0,
    required_role VARCHAR(20),            -- NULL이면 모든 사용자 접근 가능
    icon          VARCHAR(50),
    is_active     BOOLEAN DEFAULT true,
    created_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at    TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

| 타입 | 설명 |
|------|------|

## 메뉴 트리 조회 흐름

```
클라이언트 요청 → GET /api/menus/tree?role=ROLE_USER
                           ↓
        MenuController.getMenuTree(role)
                           ↓
        MenuService.getMenuTreeByRole(role)
                           ↓
        MenuMapper.findMenuTreeByRole(role)  ← PostgreSQL 재귀 CTE
                           ↓
        buildMenuTree() → 부모-자식 관계 설정
        sortMenusByOrderNum() → orderNum 기준 정렬
                           ↓
        List<Menu> (트리 구조) 반환
```

### 재귀 CTE 쿼리 핵심

```sql
WITH RECURSIVE menu_tree AS (
    SELECT * FROM menus WHERE parent_id IS NULL AND is_active = true
    UNION ALL
    SELECT m.* FROM menus m
    INNER JOIN menu_tree mt ON m.parent_id = mt.id
    WHERE m.is_active = true
),
accessible_roles AS (
    SELECT #{role} as role
    UNION ALL
    SELECT rh.child_role FROM role_hierarchy rh
    INNER JOIN accessible_roles ar ON rh.parent_role = ar.role
)
SELECT * FROM menu_tree
WHERE required_role IS NULL
   OR required_role IN (SELECT role FROM accessible_roles)
ORDER BY parent_id NULLS FIRST, order_num
```

`role_hierarchy` 테이블로 역할 계층 관리 (ADMIN은 USER 메뉴도 볼 수 있음)

## 메뉴 추가/수정 방법

### SQL로 직접 추가 (로컬 + EC2)

로컬:
```bash
docker exec palantier-postgres psql -U palantier_user -d palantier -c "SQL문"
```

EC2:
```bash
ssh -i "키.pem" ubuntu@43.200.241.26 "PGPASSWORD=palantier_password psql -h localhost -U palantier_user -d palantier -c \"SQL문\""
```

### 최상위 메뉴 추가
```sql
INSERT INTO menus (name, path, menu_type, order_num, required_role)
VALUES ('메뉴명', '/경로', 'HEADER', 순서, 'ROLE_USER');
```

### 하위 메뉴 추가
```sql
-- 부모 ID 확인
SELECT id FROM menus WHERE name = '부모메뉴명';

-- 하위 메뉴 추가
INSERT INTO menus (name, path, parent_id, menu_type, order_num, required_role)
VALUES ('하위메뉴명', '/경로', 부모ID, 'SUB', 순서, 'ROLE_USER');
```

### 메뉴 수정
```sql
UPDATE menus
SET name = '변경이름', path = '/변경경로', updated_at = CURRENT_TIMESTAMP
WHERE id = 메뉴ID;
```
