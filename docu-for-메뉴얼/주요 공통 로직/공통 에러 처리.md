# 공통 에러 처리

## 구조 개요

```
common/
├── exception/
│   ├── ErrorCode.java            # 에러 코드 enum
│   ├── GlobalExceptionHandler.java  # 전역 예외 핸들러 (@RestControllerAdvice)
│   ├── AuthenticationException.java
│   ├── AccountInactiveException.java
│   ├── DuplicateEmailException.java
│   ├── InvalidTokenException.java
│   └── UserNotFoundException.java
└── dto/
    └── ErrorResponse.java        # 공통 에러 응답 형식
```

---

## ErrorCode enum

모든 에러 코드는 `ErrorCode` enum에 정의되어 있음

```java
public enum ErrorCode {
    // 인증 (401)
    AUTHENTICATION_FAILED, INVALID_CREDENTIALS, INVALID_TOKEN, EXPIRED_TOKEN,
    INVALID_TOKEN_TYPE, REFRESH_TOKEN_NOT_FOUND,

    // 권한 (403)
    ACCOUNT_INACTIVE, ACCESS_DENIED,

    // 리소스 (404)
    USER_NOT_FOUND,

    // 중복 (409)
    DUPLICATE_EMAIL,

    // 서버 (500)
    INTERNAL_SERVER_ERROR;

    private final String code;
    private final String message;
    private final HttpStatus httpStatus;
}
```

## ErrorResponse 형식

모든 에러는 아래 형식으로 반환됨

```json
{
  "errorCode": "INVALID_CREDENTIALS",
  "message": "이메일 또는 비밀번호가 일치하지 않습니다",
  "timestamp": "2024-01-15T10:30:00",
  "path": "/api/auth/login"
}
```

생성 방법:
```java
ErrorResponse.of(errorCode, message, request.getRequestURI())
```

## GlobalExceptionHandler 처리 목록

| 예외 클래스 | HTTP 상태 | ErrorCode |
|------------|-----------|-----------|
| `AuthenticationException` | 401 | AUTHENTICATION_FAILED, INVALID_CREDENTIALS 등 |
| `AccountInactiveException` | 403 | ACCOUNT_INACTIVE |
| `DuplicateEmailException` | 409 | DUPLICATE_EMAIL |
| `UserNotFoundException` | 404 | USER_NOT_FOUND |
| `InvalidTokenException` | 401 | INVALID_TOKEN, EXPIRED_TOKEN 등 |
| `IllegalArgumentException` | 400 | INVALID_ARGUMENT (하드코딩) |
| `IllegalStateException` | 400 | ILLEGAL_STATE (하드코딩) |
| `Exception` (fallback) | 500 | INTERNAL_SERVER_ERROR |

## 커스텀 예외 생성 패턴

```java
// 예외 클래스 (ErrorCode를 생성자로 받음)
public class AuthenticationException extends RuntimeException {
    private final ErrorCode errorCode;
    public AuthenticationException(ErrorCode errorCode) {
        super(errorCode.getMessage());
        this.errorCode = errorCode;
    }
}

// 사용
throw new AuthenticationException(ErrorCode.INVALID_CREDENTIALS);
throw new UserNotFoundException(ErrorCode.USER_NOT_FOUND);
throw new DuplicateEmailException(ErrorCode.DUPLICATE_EMAIL);

// 간단한 경우 (별도 예외 클래스 없이)
throw new IllegalArgumentException("폴더를 찾을 수 없습니다: " + id);
```

## 프론트엔드 에러 처리

Axios 인터셉터에서 공통 처리:
- 401 → 토큰 재발급 시도 (`authStore.restoreAuth`)
- 재발급 실패 → 로그아웃
- 그 외 → 에러 그대로 throw

```typescript
// authStore.ts - restoreAuth 내 에러 처리
if (status === 401 || status === 403) {
    // 리프레시 토큰으로 재발급 시도
    // 재발급 실패 시 → authActions.logout()
} else {
    // 네트워크/서버 오류 → 토큰 유지 (로그아웃 안 함)
}
```
