# 프론트엔드 컴포넌트 설계

## 📐 전체 구조

### 페이지 라우팅
```
/study → StudyPage (스터디 메인 페이지)
```

### 컴포넌트 계층
```
StudyPage
├── StudyCategorySidebar  (좌측 카테고리 트리)
├── StudyPostList         (중앙 게시글 목록)
└── StudyPostDetail       (우측 게시글 뷰어 / 에디터)
    └── StudyCommentList  (댓글 목록 + 작성)
```

### 2. StudyCategorySidebar (카테고리 트리)

**파일**: `parantier-front/src/features/study/components/StudyCategorySidebar.tsx`

**역할**:
- 계층적 카테고리 트리 렌더링
- 아코디언 방식 접기/펼치기
- 선택된 카테고리 하이라이트

**Props**:
```typescript
interface StudyCategorySidebarProps {
  selectedId: number | null
  onSelect: (id: number) => void
}
```

**구현 예시**:
```tsx
export function StudyCategorySidebar({ selectedId, onSelect }: StudyCategorySidebarProps) {
  const { data: categories = [] } = useStudyCategoryTree()
  const [expandedIds, setExpandedIds] = useState<Set<number>>(new Set())

  const toggleExpand = (id: number) => {
    setExpandedIds((prev) => {
      const next = new Set(prev)
      next.has(id) ? next.delete(id) : next.add(id)
      return next
    })
  }

  const renderTree = (nodes: StudyCategory[], depth = 0) =>
    nodes.map((node) => (
      <div key={node.id}>
        <div
          className={cn(
            'flex items-center gap-1 px-3 py-1.5 text-sm cursor-pointer rounded transition-colors',
            selectedId === node.id ? 'bg-blue-50 text-blue-700' : 'hover:bg-gray-100 text-gray-700'
          )}
          style={{ paddingLeft: `${depth * 14 + 12}px` }}
          onClick={() => onSelect(node.id)}
        >
          {node.children?.length > 0 && (
            <span
              className="text-[10px] text-gray-400 w-3 shrink-0"
              onClick={(e) => { e.stopPropagation(); toggleExpand(node.id) }}
            >
              {expandedIds.has(node.id) ? '▼' : '▶'}
            </span>
          )}
          <span>{node.icon || '📁'}</span>
          <span className="truncate">{node.name}</span>
        </div>
        {expandedIds.has(node.id) && node.children?.length > 0 && (
          renderTree(node.children, depth + 1)
        )}
      </div>
    ))

  return (
    <aside className="w-60 border-r bg-white overflow-y-auto shrink-0">
      <div className="px-3 py-2 border-b bg-gray-50">
        <span className="text-sm font-medium">카테고리</span>
      </div>
      <div className="py-1">{renderTree(categories)}</div>
    </aside>
  )
}
```

### 3. StudyPostList (게시글 목록)

**파일**: `parantier-front/src/features/study/components/StudyPostList.tsx`

**역할**:
- 선택된 카테고리의 게시글 목록 표시
- 검색 필터 (Enter 입력 시 검색)
- 새 게시글 추가 버튼

**Props**:
```typescript
interface StudyPostListProps {
  categoryId: number | null
  selectedPostId: number | null
  onSelectPost: (id: number) => void
  onNewPost: () => void
}
```

**구현 예시**:
```tsx
export function StudyPostList({ categoryId, selectedPostId, onSelectPost, onNewPost }: StudyPostListProps) {
  const [inputValue, setInputValue] = useState('')
  const [searchQuery, setSearchQuery] = useState('')

  const { data: posts = [] } = useStudyPosts({ categoryId, keyword: searchQuery })

  if (!categoryId) {
    return (
      <div className="w-2/5 border-r flex items-center justify-center text-sm text-gray-400">
        좌측에서 카테고리를 선택하세요
      </div>
    )
  }

  return (
    <div className="w-2/5 border-r flex flex-col bg-white">
      {/* 검색 & 추가 */}
      <div className="flex items-center gap-1.5 px-2 py-1.5 border-b bg-gray-50">
        <div className="flex items-center flex-1 border rounded bg-white px-1.5 py-0.5">
          <svg className="w-3 h-3 text-gray-400 shrink-0" fill="none" stroke="currentColor" viewBox="0 0 24 24">
            <path strokeLinecap="round" strokeLinejoin="round" strokeWidth={2} d="M21 21l-4.35-4.35M17 11A6 6 0 1 1 5 11a6 6 0 0 1 12 0z" />
          </svg>
          <input
            type="text"
            value={inputValue}
            onChange={(e) => setInputValue(e.target.value)}
            onKeyDown={(e) => {
              if (e.key === 'Enter') { setSearchQuery(inputValue); e.currentTarget.blur() }
              if (e.key === 'Escape') { setInputValue(''); setSearchQuery('') }
            }}
            placeholder="검색 후 Enter..."
            className="flex-1 text-xs bg-transparent outline-none px-1 placeholder-gray-300"
          />
          {(inputValue || searchQuery) && (
            <button onClick={() => { setInputValue(''); setSearchQuery('') }} className="text-gray-300 hover:text-gray-500 text-xs">×</button>
          )}
        </div>
        <button
          onClick={onNewPost}
          className="px-2 py-0.5 text-xs bg-gray-600 text-white rounded hover:bg-gray-700 shrink-0"
        >
          + 글쓰기
        </button>
      </div>

      {/* 게시글 목록 */}
      <div className="flex-1 overflow-y-auto">
        {posts.length === 0 ? (
          <p className="text-xs text-gray-400 text-center py-6">게시글이 없습니다.</p>
        ) : (
          posts.map((post) => (
            <div
              key={post.id}
              onClick={() => onSelectPost(post.id)}
              className={cn(
                'px-4 py-3 border-b cursor-pointer transition-colors',
                selectedPostId === post.id ? 'bg-blue-50' : 'hover:bg-gray-50'
              )}
            >
              <div className="flex items-center gap-1 mb-1">
                {post.isPinned && <span className="text-xs">📌</span>}
                <h3 className="text-sm font-medium truncate">{post.title}</h3>
              </div>
              <div className="flex items-center gap-2 text-xs text-gray-400">
                <span>{post.authorName}</span>
                <span>·</span>
                <span>{post.createdAt.slice(0, 10)}</span>
                <span>·</span>
                <span>👁 {post.viewCount}</span>
                <span>·</span>
                <span>💬 {post.commentCount}</span>
                <span>·</span>
                <span>👍 {post.likeCount}</span>
              </div>
            </div>
          ))
        )}
      </div>
    </div>
  )
}
```

### 4. StudyPostDetail (게시글 뷰어 / 에디터)

**파일**: `parantier-front/src/features/study/components/StudyPostDetail.tsx`

**역할**:
- 읽기 모드: LexicalViewer로 본문 렌더링 + 댓글
- 편집 모드: LexicalEditor로 작성/수정

**Props**:
```typescript
interface StudyPostDetailProps {
  postId: number | null
  categoryId: number | null
  isEditing: boolean
  onToggleEdit: (editing: boolean) => void
  onSaved: (id: number) => void
  onDeleted: () => void
}
```

**구현 예시**:
```tsx
import { LexicalEditor } from '@/shared/ui/lexical/LexicalEditor'
import { LexicalViewer } from '@/shared/ui/lexical/LexicalViewer'

export function StudyPostDetail({ postId, categoryId, isEditing, onToggleEdit, onSaved, onDeleted }: StudyPostDetailProps) {
  const { data: post } = useStudyPost(postId)
  const [formTitle, setFormTitle] = useState('')
  const [formContent, setFormContent] = useState('')

  useEffect(() => {
    if (post) {
      setFormTitle(post.title)
      setFormContent(post.content)
    }
  }, [post])

  if (!isEditing && !postId) {
    return (
      <div className="flex-1 flex items-center justify-center text-sm text-gray-400">
        좌측에서 게시글을 선택하거나 새 글을 작성하세요.
      </div>
    )
  }

  return (
    <div className="flex-1 flex flex-col min-w-0 bg-white overflow-y-auto">
      {/* 헤더 */}
      <div className="flex items-center justify-between px-4 py-2 border-b bg-gray-50 shrink-0">
        <span className="text-sm font-medium">
          {isEditing ? (postId ? '게시글 편집' : '새 게시글') : '게시글'}
        </span>
        <div className="flex gap-1">
          {isEditing ? (
            <>
              <button onClick={handleSave} className="px-3 py-1 text-xs bg-gray-600 text-white rounded hover:bg-gray-700">저장</button>
              <button onClick={() => onToggleEdit(false)} className="px-3 py-1 text-xs bg-gray-400 text-white rounded hover:bg-gray-500">취소</button>
            </>
          ) : post ? (
            <>
              <button onClick={() => onToggleEdit(true)} className="px-3 py-1 text-xs bg-gray-600 text-white rounded hover:bg-gray-700">편집</button>
              <button onClick={handleDelete} className="px-3 py-1 text-xs bg-red-500 text-white rounded hover:bg-red-600">삭제</button>
            </>
          ) : null}
        </div>
      </div>

      {isEditing ? (
        /* 편집 모드 */
        <div className="p-4 space-y-3">
          <input
            type="text"
            value={formTitle}
            onChange={(e) => setFormTitle(e.target.value)}
            placeholder="제목을 입력하세요"
            className="w-full border rounded px-3 py-2 text-sm"
          />
          <div className="border rounded overflow-hidden">
            <LexicalEditor
              initialState={formContent}
              onChange={setFormContent}
              placeholder="내용을 입력하세요..."
              minHeight="300px"
            />
          </div>
        </div>
      ) : post ? (
        /* 읽기 모드 */
        <div className="p-4 space-y-4">
          {/* 게시글 메타 */}
          <div>
            <h1 className="text-xl font-bold mb-1">{post.title}</h1>
            <div className="flex items-center gap-2 text-xs text-gray-400">
              <span>{post.authorName}</span>
              <span>·</span>
              <span>{post.createdAt.slice(0, 10)}</span>
              <span>·</span>
              <span>👁 {post.viewCount}</span>
            </div>
          </div>

          {/* 본문 */}
          <div className="border rounded p-4 bg-white">
            <LexicalViewer content={post.content} />
          </div>

          {/* 좋아요 */}
          <div className="flex items-center gap-2">
            <button
              onClick={handleLike}
              className={cn(
                'flex items-center gap-1 px-3 py-1.5 text-sm rounded border transition-colors',
                post.isLiked ? 'bg-blue-50 border-blue-300 text-blue-600' : 'hover:bg-gray-50'
              )}
            >
              👍 {post.likeCount}
            </button>
          </div>

          {/* 댓글 */}
          <StudyCommentList postId={post.id} />
        </div>
      ) : null}
    </div>
  )
}
```

### 5. StudyCommentList (댓글)

```tsx
export function StudyCommentList({ postId }: { postId: number }) {
  const [commentText, setCommentText] = useState('')

          </div>
          <p className="text-sm text-gray-700">{comment.content}</p>
        </div>
      ))}

      {/* 댓글 작성 */}
      <div className="flex gap-2">
        <textarea
          value={commentText}
          onChange={(e) => setCommentText(e.target.value)}
          placeholder="댓글을 입력하세요..."
          rows={2}
          className="flex-1 border rounded px-3 py-2 text-sm resize-none focus:outline-none"
        />
        <button
          onClick={() => { createComment.mutate(commentText); setCommentText('') }}
          disabled={!commentText.trim()}
          className="px-3 py-2 text-xs bg-gray-600 text-white rounded hover:bg-gray-700 disabled:opacity-50 shrink-0"
        >
          등록
        </button>
      </div>
    </div>
  )
```

## 🔄 TanStack Query Hooks

**폴더**: `parantier-front/src/features/study/hooks/`

```typescript
// useStudyCategoryTree.ts
export function useStudyCategoryTree() {
  return useQuery({
    queryKey: ['study-categories'],
    queryFn: () => apiClient.get('/study/categories').then((r) => r.data),
  })
}

// useStudyPosts.ts
export function useStudyPosts(params: { categoryId?: number | null; keyword?: string }) {
  return useQuery({
    queryKey: ['study-posts', params],
    queryFn: () => apiClient.get('/study/posts', { params }).then((r) => r.data),
    enabled: !!params.categoryId,
  })
}

// useStudyPost.ts
export function useStudyPost(postId: number | null) {
  return useQuery({
    queryKey: ['study-post', postId],
    queryFn: () => apiClient.get(`/study/posts/${postId}`).then((r) => r.data),
    enabled: !!postId,
  })
}

// useStudyComments.ts
export function useStudyComments(postId: number) {
  return useQuery({
    queryKey: ['study-comments', postId],
    queryFn: () => apiClient.get(`/study/posts/${postId}/comments`).then((r) => r.data),
  })
}

// useCreateStudyPost.ts
export function useCreateStudyPost(categoryId: number | null, onSuccess: (id: number) => void) {
  const queryClient = useQueryClient()
  return useMutation({
    mutationFn: (data: { title: string; content: string }) =>
      apiClient.post('/study/posts', { ...data, categoryId }).then((r) => r.data),
    onSuccess: (res) => {
      queryClient.invalidateQueries({ queryKey: ['study-posts'] })
      toast.success('게시글이 저장되었습니다')
      onSuccess(res.id)
    },
  })
}

// useUpdateStudyPost.ts
export function useUpdateStudyPost(postId: number, onSuccess: () => void) {
  const queryClient = useQueryClient()
  return useMutation({
    mutationFn: (data: { title: string; content: string }) =>
      apiClient.put(`/study/posts/${postId}`, data).then((r) => r.data),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['study-posts'] })
      queryClient.invalidateQueries({ queryKey: ['study-post', postId] })
      toast.success('게시글이 수정되었습니다')
      onSuccess()
    },
  })
}

// useDeleteStudyPost.ts
export function useDeleteStudyPost(onSuccess: () => void) {
  const queryClient = useQueryClient()
  return useMutation({
    mutationFn: (postId: number) =>
      apiClient.delete(`/study/posts/${postId}`).then((r) => r.data),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['study-posts'] })
      toast.success('게시글이 삭제되었습니다')
      onSuccess()
    },
  })
}

// useCreateStudyComment.ts
export function useCreateStudyComment(postId: number) {
  const queryClient = useQueryClient()
  return useMutation({
    mutationFn: (content: string) =>
      apiClient.post(`/study/posts/${postId}/comments`, { content }).then((r) => r.data),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['study-comments', postId] })
    },
  })
}

// useToggleStudyLike.ts
export function useToggleStudyLike(postId: number) {
  const queryClient = useQueryClient()
  return useMutation({
    mutationFn: () =>
      apiClient.post(`/study/posts/${postId}/like`).then((r) => r.data),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['study-post', postId] })
    },
  })
}
```
