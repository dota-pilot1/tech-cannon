## 1. 개요

챌린지 메뉴는 단순 문서 관리가 아니라 **실제 챌린지를 출제하고 팀원이 풀이를 제출**하는 기능입니다.

### 핵심 특징

| 항목 | 내용 |
|------|------|
| **URL 경로** | `/challenge` |
| **백엔드 API Base** | `/api/challenge` |
| **참조 페이지** | SpringAI 페이지 — 동일한 2중 사이드바 UI 구조 |
| **접근 권한** | 로그인 사용자 전체 조회·제출 가능, ADMIN만 카테고리/섹션/주제 편집 가능 |
| **DB 네임스페이스** | `challenge_` 접두사 테이블 4개 사용 |

### 구조 개요 (3-Depth + 제출)

```
챌린지 메뉴
├── Category (챌린지 유형)       ← 좌측 1번 패널 (예: 데일리 챌린지, 알고리즘, SQL)
│   ├── Section (챌린지 회차)    ← 좌측 2번 패널 (예: 2025-07-01, Week 1)
│   │   ├── Topic (주제)         ← 본문 상단 — ADMIN이 설정한 챌린지 주제/문제
│   │   └── Submissions (제출)   ← 본문 하단 — 팀원들의 풀이 제출 목록
│   └── Section
└── Category
```

> **SpringAI 페이지와 동일한 2단 사이드바 레이아웃**을 사용하되,  
> 우측 본문은 "문서 에디터" 대신 **"챌린지 주제 + 풀이 제출" 전용 UI**로 구성합니다.  
> 화면은 현재 ChallengePage처럼 **가운데 컴팩트한 카드 스타일**을 유지합니다.

## 3. 헤더 정리

현재 헤더에 노출된 챌린지 관련 탭 메뉴 중 **실구현되지 않은 더미 탭들을 제거**합니다.

### 현재 → 변경 후

| 현재 탭 | 변경 |
|---------|------|
| 데일리 챌린지 | → 카테고리로 이동 (1차 사이드바에서 관리) |
| 알고리즘 | → 카테고리로 이동 |
| SQL 챌린지 | → 카테고리로 이동 |
| 코드 리뷰 | → 일단 제거 (추후 별도 구현) |
| 랭킹 | → 일단 제거 (추후 별도 구현) |

- `ChallengePage.tsx`의 `menuItems`, `TabKey`, 각 Tab 함수들(DailyTab, AlgoTab, SqlTab, ReviewTab, RankTab) 전부 제거
- 대신 SpringAI와 동일한 2중 사이드바 구조로 완전 교체
- 탭 기반 URL(`?tab=daily` 등) 파라미터도 제거

## 4. DB 테이블 구조

### 4.1 challenge_categories

챌린지 유형 (데일리 챌린지, 알고리즘, SQL 등)

```sql
CREATE TABLE challenge_categories (
    id         BIGINT AUTO_INCREMENT PRIMARY KEY,
    name       VARCHAR(100)  NOT NULL,
    icon       VARCHAR(50),
    emoji      VARCHAR(10),
    order_num  INT           NOT NULL DEFAULT 0,
    is_active  BOOLEAN       NOT NULL DEFAULT TRUE,
    created_at DATETIME      DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME      DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

### 4.2 challenge_sections

챌린지 회차/날짜 (예: "2025-07-14", "Week 1")

```sql
CREATE TABLE challenge_sections (
    id          BIGINT AUTO_INCREMENT PRIMARY KEY,
    category_id BIGINT        NOT NULL,
    title       VARCHAR(200)  NOT NULL,
    order_num   INT           NOT NULL DEFAULT 0,
    is_active   BOOLEAN       NOT NULL DEFAULT TRUE,
    created_at  DATETIME      DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME      DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (category_id) REFERENCES challenge_categories(id) ON DELETE CASCADE
);
```

### 4.3 challenge_topics

섹션(회차)에 대한 챌린지 주제/문제 블록 (SpringAI의 blocks와 동일 구조)  
ADMIN이 작성하는 문제 본문.

```sql
CREATE TABLE challenge_topics (
    id          BIGINT AUTO_INCREMENT PRIMARY KEY,
    section_id  BIGINT        NOT NULL,
    block_type  VARCHAR(20)   NOT NULL,   -- NOTE, CODE, MMD 등
    content     LONGTEXT      NOT NULL,
    sort_order  INT           NOT NULL DEFAULT 0,
    updated_by  BIGINT,
    created_at  DATETIME      DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME      DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (section_id) REFERENCES challenge_sections(id) ON DELETE CASCADE
);
```

> block_type 은 기존 TaskBlock 타입 그대로 사용 (NOTE, CODE, MMD, IMAGE 등)

### 4.4 challenge_submissions

팀원들의 풀이 제출

```sql
CREATE TABLE challenge_submissions (
    id          BIGINT AUTO_INCREMENT PRIMARY KEY,
    section_id  BIGINT        NOT NULL,
    user_id     BIGINT        NOT NULL,
    language    VARCHAR(20)   NOT NULL DEFAULT 'TEXT',  -- JAVA, PYTHON, SQL, JAVASCRIPT, TEXT 등
    content     LONGTEXT      NOT NULL,
    created_at  DATETIME      DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME      DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (section_id) REFERENCES challenge_sections(id) ON DELETE CASCADE
);
```

### 테이블 관계도

```
challenge_categories (1)
    └── challenge_sections (N)
            ├── challenge_topics (N)       ← ADMIN이 작성하는 문제 본문 블록
            └── challenge_submissions (N)  ← 팀원들이 제출하는 풀이
```

### 6.4 Service 핵심 로직

**주제 저장** — SpringAiDocService.saveBlocks와 동일한 Delete & Re-Insert 전략
```java
@Transactional
public void saveTopics(Long sectionId, List<ChallengeTopicDto> topics, Long userId) {
    topicMapper.deleteBySectionId(sectionId);
    if (topics == null || topics.isEmpty()) return;
    for (int i = 0; i < topics.size(); i++) {
        ChallengeTopicDto dto = topics.get(i);
        ChallengeTopic topic = ChallengeTopic.builder()
            .sectionId(sectionId)
            .blockType(dto.getBlockType())
            .content(dto.getContent())
            .sortOrder(i)
            .updatedBy(userId)
            .build();
        topicMapper.insert(topic);
    }
}
```

**풀이 제출** — 중복 제출 방지 (선택): 동일 섹션에 동일 유저는 1개만 허용하거나 여러 번 허용 중 선택
```java
@Transactional
public void createSubmission(Long sectionId, ChallengeSubmissionRequest req, Long userId) {
    ChallengeSubmission submission = ChallengeSubmission.builder()
        .sectionId(sectionId)
        .userId(userId)
        .language(req.getLanguage())
        .content(req.getContent())
        .build();
    submissionMapper.insert(submission);
}
```

**풀이 수정** — 본인 확인 후 수정
```java
@Transactional
public void updateSubmission(Long id, ChallengeSubmissionRequest req, Long userId) {
    ChallengeSubmission existing = submissionMapper.findById(id)
        .orElseThrow(() -> new ResourceNotFoundException(ErrorCode.CHALLENGE_SUBMISSION_NOT_FOUND));
    if (!existing.getUserId().equals(userId)) {
        throw new ForbiddenException(ErrorCode.FORBIDDEN);
    }
    submissionMapper.update(id, req.getLanguage(), req.getContent());
}
```

**ChallengeSubmissionMapper.xml** — submissions 조회 시 users 테이블과 JOIN하여 userName 포함
```xml
<select id="findBySectionId" resultMap="ChallengeSubmissionResultMap">
    SELECT
        s.id, s.section_id, s.user_id, u.name as user_name,
        s.language, s.content, s.created_at, s.updated_at
    FROM challenge_submissions s
    LEFT JOIN users u ON s.user_id = u.id
    WHERE s.section_id = #{sectionId}
    ORDER BY s.created_at ASC
</select>
```

> `users` 테이블의 정확한 컬럼명은 기존 UserMapper.xml 참조

```typescript
const API_BASE = import.meta.env.VITE_API_URL || "http://localhost:8080";

  Authorization: `Bearer ${localStorage.getItem("accessToken") ?? ""}`,

export interface ChallengeCategory {
  id: number;
  name: string;
  icon: string;
  emoji: string;
  orderNum: number;
}

  getCategories: (): Promise<ChallengeCategory[]> =>

  createCategory: (data: { name: string; icon: string; emoji: string; orderNum: number }) =>

    }).then((r) => { if (!r.ok) throw new Error(); }),

  deleteCategory: (id: number) =>
    fetch(`${BASE}/challenge/categories/${id}`, {
      method: "DELETE", headers: getAuthHeaders(),
    }).then((r) => { if (!r.ok) throw new Error(); }),

  reorderCategories: (items: { id: number; orderNum: number }[]) =>
    fetch(`${BASE}/challenge/categories/reorder`, {
      method: "PUT", headers: getAuthHeaders(), body: JSON.stringify(items),
    }).then((r) => { if (!r.ok) throw new Error(); }),

  // 섹션
  getSections: (categoryId: number): Promise<ChallengeSection[]> =>
    fetch(`${BASE}/challenge/categories/${categoryId}/sections`, { headers: getAuthHeaders() })
      .then((r) => r.json()).then((d) => Array.isArray(d) ? d : []),

  createSection: (data: { categoryId: number; title: string; orderNum: number }) =>
    fetch(`${BASE}/challenge/sections`, {
      method: "POST", headers: getAuthHeaders(), body: JSON.stringify(data),
    }).then((r) => { if (!r.ok) throw new Error(); }),

  updateSection: (id: number, data: { title: string; orderNum: number }) =>
    fetch(`${BASE}/challenge/sections/${id}`, {
      method: "PUT", headers: getAuthHeaders(), body: JSON.stringify(data),
    }).then((r) => { if (!r.ok) throw new Error(); }),

  deleteSection: (id: number) =>
    fetch(`${BASE}/challenge/sections/${id}`, {
      method: "DELETE", headers: getAuthHeaders(),
    }).then((r) => { if (!r.ok) throw new Error(); }),

  reorderSections: (items: { id: number; orderNum: number }[]) =>
    fetch(`${BASE}/challenge/sections/reorder`, {
      method: "PUT", headers: getAuthHeaders(), body: JSON.stringify(items),
    }).then((r) => { if (!r.ok) throw new Error(); }),

  // 주제 블록
  getTopics: (sectionId: number): Promise<ChallengeTopic[]> =>
    fetch(`${BASE}/challenge/sections/${sectionId}/topics`, { headers: getAuthHeaders() })
      .then((r) => r.json()).then((d) => Array.isArray(d) ? d : []),

  saveTopics: (sectionId: number, topics: ChallengeTopic[]) =>
    fetch(`${BASE}/challenge/sections/${sectionId}/topics`, {
      method: "PUT", headers: getAuthHeaders(), body: JSON.stringify(topics),
    }).then((r) => { if (!r.ok) throw new Error("주제 저장 실패"); }),

  // 풀이 제출
  getSubmissions: (sectionId: number): Promise<ChallengeSubmission[]> =>
    fetch(`${BASE}/challenge/sections/${sectionId}/submissions`, { headers: getAuthHeaders() })
      .then((r) => r.json()).then((d) => Array.isArray(d) ? d : []),

  createSubmission: (sectionId: number, data: { language: string; content: string }) =>
    fetch(`${BASE}/challenge/sections/${sectionId}/submissions`, {
      method: "POST", headers: getAuthHeaders(), body: JSON.stringify(data),
    }).then((r) => { if (!r.ok) throw new Error("제출 실패"); }),

  updateSubmission: (id: number, data: { language: string; content: string }) =>
    fetch(`${BASE}/challenge/submissions/${id}`, {

    }).then((r) => { if (!r.ok) throw new Error("수정 실패"); }),

  deleteSubmission: (id: number) =>
    fetch(`${BASE}/challenge/submissions/${id}`, {
      method: "DELETE", headers: getAuthHeaders(),
    }).then((r) => { if (!r.ok) throw new Error("삭제 실패"); }),
};
```
