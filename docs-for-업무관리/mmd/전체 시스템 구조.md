## 데이터 구조

```mermaid
erDiagram
    organizations ||--o{ task_folders : "has many"
    users ||--o{ task_folders : "creates"

    task_folders ||--o{ task_folders : "parent-child"
    task_folders ||--o{ task_posts : "contains"

    users ||--o{ task_posts : "authors"
    task_posts ||--o{ task_blocks : "has blocks"
    task_posts ||--o{ task_comments : "has comments"

    users ||--o{ task_comments : "writes"

    organizations {
        bigint id PK
        string name
    }

    users {
        bigint id PK
        string username
        bigint organization_id FK
    }

    task_folders {
        bigint id PK
        bigint organization_id FK
        bigint parent_id FK
        string name
        int sort_order
    }

    task_posts {
        bigint id PK
        bigint folder_id FK
        bigint author_id FK
        string title
    }

    task_blocks {
        bigint id PK
        bigint post_id FK
        string block_type
        text content
        int sort_order
    }

    task_comments {
        bigint id PK
        bigint post_id FK
        bigint author_id FK
        text content
    }
```


## 사용자 플로우

```mermaid
sequenceDiagram
    participant U as User
    participant S as Sidebar
    participant L as PostList
    participant D as Detail
    participant B as Backend

    U->>S: 폴더 선택
    S->>B: GET /api/tasks/posts?folderId=1
    B-->>L: 게시글 목록 반환

    U->>L: 게시글 클릭
    L->>B: GET /api/tasks/posts/123
    B-->>D: 게시글 + 블록들 반환

    U->>D: 편집 버튼
    D->>D: 편집 모드 전환

    U->>D: 블록 추가/수정
    U->>D: 저장 버튼
    D->>B: PUT /api/tasks/posts/123
    B-->>D: 저장 완료
    D->>D: 조회 모드 전환
```
