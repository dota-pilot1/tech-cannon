# Lexical Editor 적용 계획

## 목표

업무 관리(Task) 의 **NOTE 블록 편집** 영역을 기존 `<textarea>` 에서
`coupon_project` 의 Lexical Editor로 교체한다.

---

## 현재 상태 분석

### 현재 NOTE 블록 편집 방식
- `TaskBlockEditor.tsx` 내부에서 `<textarea>` 로 단순 텍스트 입력
- 저장 형식: plain text (string)
- 뷰어(`TaskBlockViewer.tsx`)에서 `<pre>` 태그로 렌더링

### 참고 구현체 (coupon_project)
- `src/components/lexical/LexicalEditor.tsx` — 에디터 본체
- `src/components/lexical/LexicalViewer.tsx` — 읽기 전용 뷰어
- `src/components/lexical/theme.ts` — 스타일 테마
- `src/components/lexical/toolbar/ToolbarPlugin.tsx` — 툴바
  - `TextFormatButtons.tsx` — Bold / Italic / Underline
  - `BlockTypeButtons.tsx` — H1 / H2 / H3 / UL / OL
  - `CodeBlockButton.tsx` — 코드 블록
- 저장 형식: **Lexical EditorState JSON** (문자열)

## 데이터 호환성 처리

### 문제
기존 NOTE 블록의 `content` 는 plain text.
Lexical은 JSON 형식으로 저장.
→ 기존 데이터를 에디터에 불러올 때 JSON 파싱 실패 시 plain text로 fallback 처리 필요.

### 해결 방법 (InitialContentPlugin)
coupon_project의 `InitialContentPlugin` 이 이미 이 처리를 포함하고 있음:

```
1. JSON.parse 시도
2. parsed.root 존재 → Lexical EditorState로 로드
3. 파싱 실패 → 줄바꿈 기준으로 paragraph 노드로 변환하여 로드
```

→ **별도 마이그레이션 없이 기존 데이터 호환** 가능

## 작업 순서

1. **패키지 설치**
   ```bash
   cd parantier-front && npm install lexical @lexical/react @lexical/rich-text \
     @lexical/list @lexical/code @lexical/html @lexical/selection @lexical/utils
   ```

2. **lexical 파일 이식**
   - `src/shared/ui/lexical/` 폴더 생성
   - coupon_project에서 7개 파일 복사 후 `'use client'` 제거 (Vite 프로젝트이므로 불필요)
   - `namespace` 를 `'ReviewEditor'` → `'TaskEditor'` 로 변경

3. **TaskBlockEditor.tsx 수정**
   - NOTE 블록의 `<textarea>` 부분만 `<LexicalEditor>` 로 교체
   - 나머지 블록(MMD, FIGMA, FILE, DBTABLE)은 그대로 유지

4. **TaskBlockViewer.tsx 수정**
   - NOTE 블록의 `<pre>` 부분만 `<LexicalViewer>` 로 교체

5. **동작 확인**
   - 기존 plain text 데이터 불러오기 정상 동작 확인
   - 새 문서 작성 후 저장/뷰어 확인
   - 볼드/이탤릭/목록/코드블록 동작 확인

---

## 주의사항

- `'use client'` 지시자는 Next.js 전용 → Vite에서는 **제거**
- LexicalViewer는 `$generateHtmlFromNodes` 사용 → `@lexical/html` 필수
- NOTE 블록 외 다른 블록(MMD, DBTABLE 등)은 **변경하지 않음**
- 에디터 스타일(`theme.ts`)은 Tailwind 클래스 기반이므로 별도 CSS 추가 불필요
