# 채팅방 구현을 위해 기본적으로 알아야 할 것들

## 1. WebSocket과 STOMP 기본 개념

### WebSocket이란?
- HTTP와 달리 **양방향 실시간 통신**을 지원하는 프로토콜
- 서버와 클라이언트가 지속적인 연결을 유지
- 실시간 채팅, 알림, 게임 등에 사용

### STOMP (Simple Text Oriented Messaging Protocol)
- WebSocket 위에서 동작하는 **메시징 프로토콜**
- Pub/Sub 패턴 지원
- 메시지 라우팅, 구독 관리 등의 기능 제공

### 주요 개념
```
Client A → subscribe → Server (브로커)
                         ↓
                   /topic/messages
                         ↓
         Client B ← broadcast ← Client C
```

## 2. Backend (Spring Boot) 구조

### 의존성
```gradle
implementation 'org.springframework.boot:spring-boot-starter-websocket'
```

### WebSocket 설정
파일: `parantier-api/src/main/java/com/mapo/palantier/config/WebSocketConfig.java`

```java
@Configuration
@EnableWebSocketMessageBroker
public class WebSocketConfig implements WebSocketMessageBrokerConfigurer {
    @Override
    public void configureMessageBroker(MessageBrokerRegistry config) {
        config.enableSimpleBroker("/topic", "/queue");
        config.setApplicationDestinationPrefixes("/app");
    }

    @Override
    public void registerStompEndpoints(StompEndpointRegistry registry) {
        registry.addEndpoint("/ws")
                .setAllowedOriginPatterns("*")
                .withSockJS();
    }
}
```

**핵심 포인트:**
- `/ws`: WebSocket 연결 엔드포인트
- `/app`: 클라이언트가 메시지를 보낼 때 사용하는 prefix
- `/topic`: 1:N 브로드캐스트 (채팅방)
- `/queue`: 1:1 메시지

### Spring Security 설정
**중요**: WebSocket 엔드포인트를 Security에서 허용해야 합니다.

```java
.authorizeHttpRequests(auth -> auth
    .requestMatchers("/ws/**").permitAll()
    // ...
)
```

## 3. Frontend (React + TypeScript) 구조

### 의존성
```bash
npm install @stomp/stompjs
```

### WebSocket 클라이언트 설정
```typescript
import { Client } from '@stomp/stompjs'

const client = new Client({
  brokerURL: 'ws://localhost:8080/ws',
  reconnectDelay: 5000,
  onConnect: () => {
    client.subscribe('/topic/messages', (message) => {
      const receivedMessage = JSON.parse(message.body)
    })
  }
})

client.activate()
```

### 메시지 전송
```typescript
client.publish({
  destination: '/app/chat.send',
  body: JSON.stringify(message),
})
```

## 4. Database 구조

### 주요 테이블
```sql
CREATE TABLE chat_rooms (
    id BIGSERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    room_type VARCHAR(50) NOT NULL,
    created_by BIGINT REFERENCES users(id),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE messages (
    id BIGSERIAL PRIMARY KEY,
    room_id BIGINT REFERENCES chat_rooms(id),
    sender_id BIGINT REFERENCES users(id),
    content TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 5. 트러블슈팅

### 연결이 안 될 때

#### 증상: "연결 끊김" (빨간 점)
- **원인**: Spring Security가 `/ws` 엔드포인트 차단
- **해결**: SecurityConfig에 `.requestMatchers("/ws/**").permitAll()` 추가

#### 브라우저 콘솔 확인
- F12 → Console 탭
- `403 Forbidden` → Security 설정 누락
- `WebSocket connection failed` → 서버 미실행
