# 대시보드 실제 통계 데이터 연동 구현 계획

## 현재 상태
- `MainPage.tsx` 의 모든 통계 수치가 하드코딩되어 있음
- 진행 중인 프로젝트 5, 내 할 일 8, 팀원 24 등 → 실제 DB 데이터와 무관

---

## 목표
대시보드에 실제 업무/이슈 통계를 보여주는 API 연동

---

## 보여줄 통계 항목

| 카드 | 데이터 소스 | 설명 |
|------|------------|------|
| 내 진행 중 업무 | `Work` | assigneeId = 나, status = IN_PROGRESS |
| 오늘 마감 업무 | `Work` | dueDate = 오늘 날짜 |
| 미해결 이슈 | `Issue` | status = OPEN or IN_PROGRESS |
| 이번 주 완료 업무 | `Work` | status = DONE, 이번 주 |
| 팀원 수 | `User` | 전체 활성 사용자 수 |
| 이번 주 완료율 | `Work` | 완료 / 전체 × 100 |

---

## 구현 방법

### 백엔드

**새 엔드포인트 추가**
```
GET /api/dashboard/stats
```

**응답 예시**
```json
{
  "myInProgressWorks": 3,
  "todayDueWorks": 2,
  "openIssues": 5,
  "weekDoneWorks": 8,
  "totalUsers": 24,
  "weekCompletionRate": 72
}
```

**구현 파일**
- `DashboardController.java` — GET /api/dashboard/stats
- `DashboardService.java` — 통계 집계 로직
- `DashboardStatsResponse.java` — 응답 DTO
- `DashboardMapper.xml` — MyBatis 집계 쿼리

---

### 프론트엔드

**새 API 모듈**
- `src/api/dashboardApi.ts` — `/api/dashboard/stats` 호출

**MainPage.tsx 수정**
- TanStack Query로 통계 데이터 fetch
- 하드코딩된 숫자 → 실제 API 응답값으로 교체
- 로딩 중 스켈레톤 UI 표시
