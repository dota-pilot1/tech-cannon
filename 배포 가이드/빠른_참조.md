# 배포 빠른 참조

> **⚡ 자동 배포 권장**: 코드를 커밋/푸시하면 GitHub Actions가 자동으로 배포합니다.
> 자세한 내용: [GitHub Actions 배포](./GitHub_Actions_배포.md)

## GitHub Actions (자동 배포)

```bash
# 1. 변경사항 커밋 및 푸시만 하면 자동 배포
git add -A
git commit -m "feat: 새 기능 추가"
git push

# 2. 배포 진행 상황 확인
# https://github.com/dota-pilot1/tech-cannon/actions

# 3. 배포 완료 확인 (2-5분 소요)
curl https://api.dxline-tallent.com/actuator/health  # 백엔드
curl -I https://dxline-tallent.com                   # 프론트엔드
```

## 수동 배포

### 프론트엔드 배포

```bash
cd parantier-front
npm run build
aws s3 sync dist s3://dxline-tallent-front --delete
aws cloudfront create-invalidation --distribution-id E11NF3HMOB52NI --paths "/*"
```

## 백엔드 배포

```bash
cd parantier-api
./gradlew build -x test

PEM="/Users/terecal/mapo-palantier-project/배포 가이드/hibot-d-server-key.pem"
scp -i "$PEM" build/libs/parantier-api-0.0.1-SNAPSHOT.jar ubuntu@43.200.241.26:/home/ubuntu/
ssh -i "$PEM" ubuntu@43.200.241.26 "sudo systemctl restart palantier-backend.service && sudo systemctl status palantier-backend.service --no-pager"
```

> 권장 방식은 GitHub Actions 자동 배포입니다. 백엔드는 `palantier-backend.service`로 등록되어 있어 EC2 재부팅 후 자동 시작됩니다.
