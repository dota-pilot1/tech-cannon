## 2026-03-28: PostgreSQL Docker vs 호스트 설치 혼란

### 문제
- 배포 가이드에는 Docker 컨테이너(`palantier-postgres`) 사용으로 명시
- 실제 서버에는 호스트에 PostgreSQL이 직접 설치되어 있음
- Docker 컨테이너는 `talent-admin-db`(다른 프로젝트)만 존재

### 해결
- 실제 DB 접속: `PGPASSWORD=palantier_password psql -h localhost -p 5432 -U palantier_user -d palantier`
- 모든 배포 가이드를 호스트 PostgreSQL 기준으로 수정

## 2026-03-27: AWS 환경 변수 누락

### 문제
- 백엔드 시작 시 `NullPointerException: Access key ID cannot be blank`
- S3Config 빈 초기화 실패

### 해결
- 시작 스크립트에 AWS 환경 변수 추가
```bash
export AWS_ACCESS_KEY_ID=<실제값>
export AWS_SECRET_ACCESS_KEY=<실제값>
export AWS_S3_BUCKET_NAME=hibot-docu
export AWS_S3_REGION=ap-northeast-2
```

## 2026-03-27: SSH PEM 파일 경로 문제

### 문제
- 가이드에 명시된 경로: `/Users/terecal/mapo-palantier-project/배포 가이드/hibot-d-server-key.pem`
- 실제 작동하는 경로: `/Users/terecal/mapo-palantier-project/배포 가이드/hibot-d-server-key.pem`

### 해결
- 올바른 PEM 파일 경로로 모든 문서 업데이트
- 권한 확인: `chmod 400 "/Users/terecal/mapo-palantier-project/배포 가이드/hibot-d-server-key.pem"`
