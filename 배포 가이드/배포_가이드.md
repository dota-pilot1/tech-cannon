## 프론트엔드 배포

### 1. 로컬에서 빌드

```bash
cd parantier-front
npm run build
```

빌드된 파일은 `dist/` 폴더에 생성됩니다.

### 2. S3에 업로드

```bash
aws s3 sync dist s3://dxline-tallent-front --delete
```

- `--delete` 옵션은 S3에서 로컬에 없는 파일을 삭제합니다.
- 업로드 후 약 4.6MB의 파일이 전송됩니다.

### 3. CloudFront 캐시 무효화

```bash
aws cloudfront create-invalidation --distribution-id E11NF3HMOB52NI --paths "/*"
```

캐시 무효화는 완료되는 데 1-5분 정도 소요됩니다.

### 4. 배포 확인

브라우저에서 다음 URL로 접속하여 확인:
- https://dxline-tallent.com
- https://d1841s1y3ps0cj.cloudfront.net

## 백엔드 배포

### 1. 로컬에서 빌드

```bash
cd parantier-api
./gradlew clean bootJar
```

빌드된 JAR 파일은 `build/libs/parantier-api-0.0.1-SNAPSHOT.jar`에 생성됩니다.

### 2. EC2에 업로드

```bash
scp -i "/Users/terecal/mapo-palantier-project/배포 가이드/hibot-d-server-key.pem" \
    parantier-api/build/libs/parantier-api-0.0.1-SNAPSHOT.jar \
    ubuntu@43.200.241.26:/home/ubuntu/
```

### 3. 기존 프로세스 종료 (EC2에서)

```bash
ssh -i "/Users/terecal/mapo-palantier-project/배포 가이드/hibot-d-server-key.pem" \
    ubuntu@43.200.241.26

# EC2 내부에서:
pkill -f 'java -jar parantier-api'
```

### 4. 새 애플리케이션 시작

```bash
# EC2 내부에서:
nohup java -jar /home/ubuntu/parantier-api-0.0.1-SNAPSHOT.jar \
    --spring.profiles.active=prod \
    > /home/ubuntu/app.log 2>&1 &
```

### 5. 배포 확인

```bash
# 헬스체크
curl http://43.200.241.26:8080/actuator/health

# 응답 예시:
# {"groups":["liveness","readiness"],"status":"UP"}
```

또는 브라우저에서:
- https://api.dxline-tallent.com/actuator/health

### 6. 로그 확인

```bash
# EC2에서 실시간 로그 확인
tail -f /home/ubuntu/app.log
```

## 트러블슈팅

### 프론트엔드 문제

#### 1. CloudFront에서 404 에러
**문제**: 라우팅 시 404 에러 발생

**해결**: CloudFront Custom Error Responses 설정 확인
- 403 → /index.html (200)
- 404 → /index.html (200)

#### 2. CORS 에러
**문제**: API 호출 시 CORS 에러

**해결**: 백엔드 SecurityConfig.java에서 allowed-origins 확인
```java
configuration.setAllowedOrigins(Arrays.asList(
    "http://localhost:5173",
    "https://d1841s1y3ps0cj.cloudfront.net",
    "https://dxline-tallent.com"
));
```

### 백엔드 문제

#### 1. 애플리케이션이 시작되지 않음
**문제**: JAR 실행 후 프로세스가 종료됨

**해결**:
```bash
# 로그 확인
cat /home/ubuntu/app.log

# 주요 확인 사항:
# - Java 버전 확인 (Java 21 필요)
# - PostgreSQL 연결 확인
# - 포트 8080이 사용 중인지 확인
```

#### 2. 데이터베이스 연결 실패
**문제**: `Connection refused` 에러

**해결**:
```bash
# PostgreSQL 컨테이너 상태 확인
docker ps | grep palantier-postgres

# PostgreSQL 재시작 (필요시)
docker restart palantier-postgres
```

#### 3. 메모리 부족
**문제**: OutOfMemoryError

**해결**: JVM 메모리 옵션 추가
```bash
nohup java -Xms512m -Xmx1024m -jar /home/ubuntu/parantier-api-0.0.1-SNAPSHOT.jar \
    --spring.profiles.active=prod \
    > /home/ubuntu/app.log 2>&1 &
```

### 일반적인 문제

#### 1. SSH 연결 실패
**문제**: Permission denied (publickey)

**해결**:
```bash
# PEM 파일 권한 확인 (400이어야 함)
chmod 400 "/Users/terecal/mapo-palantier-project/배포 가이드/hibot-d-server-key.pem"
```

#### 2. AWS CLI 설정
**문제**: AWS CLI 명령어 실패

**해결**:
```bash
# AWS 자격증명 확인
aws configure list

# 필요시 재설정
aws configure
```

## 자동 배포 스크립트

### 프론트엔드 배포 스크립트

파일: `parantier-front/deploy.sh`

```bash
#!/bin/bash
set -e

echo "🚀 프론트엔드 배포 시작..."

# 1. 빌드
echo "📦 빌드 중..."
npm run build

# 2. S3 업로드
echo "☁️  S3 업로드 중..."
aws s3 sync dist s3://dxline-tallent-front --delete

# 3. CloudFront 캐시 무효화
echo "🔄 CloudFront 캐시 무효화 중..."
aws cloudfront create-invalidation --distribution-id E11NF3HMOB52NI --paths "/*"

echo "✅ 프론트엔드 배포 완료!"
echo "🌐 https://dxline-tallent.com"
```

### 백엔드 배포 스크립트

파일: `parantier-api/deploy.sh`

```bash
#!/bin/bash
set -e

PEM_FILE="/Users/terecal/mapo-palantier-project/배포 가이드/hibot-d-server-key.pem"
EC2_HOST="ubuntu@43.200.241.26"
JAR_FILE="build/libs/parantier-api-0.0.1-SNAPSHOT.jar"

echo "🚀 백엔드 배포 시작..."

# 1. 빌드
echo "📦 빌드 중..."
./gradlew clean bootJar

# 2. EC2에 업로드
echo "☁️  EC2 업로드 중..."
scp -i "$PEM_FILE" "$JAR_FILE" "$EC2_HOST:/home/ubuntu/"

# 3. 기존 프로세스 종료
echo "🛑 기존 프로세스 종료 중..."
ssh -i "$PEM_FILE" "$EC2_HOST" "pkill -f 'java -jar parantier-api' || true"

# 4. 새 애플리케이션 시작
echo "▶️  새 애플리케이션 시작 중..."
ssh -i "$PEM_FILE" "$EC2_HOST" \
    "nohup java -jar /home/ubuntu/parantier-api-0.0.1-SNAPSHOT.jar \
    --spring.profiles.active=prod \
    > /home/ubuntu/app.log 2>&1 &"

# 5. 헬스체크 대기
echo "⏳ 애플리케이션 시작 대기 중 (15초)..."
sleep 15

# 6. 헬스체크
echo "🏥 헬스체크 중..."
HEALTH=$(curl -s http://43.200.241.26:8080/actuator/health)
echo "$HEALTH"

if echo "$HEALTH" | grep -q '"status":"UP"'; then
    echo "✅ 백엔드 배포 완료!"
    echo "🌐 https://api.dxline-tallent.com"
else
    echo "❌ 배포 실패! 로그를 확인하세요."
    ssh -i "$PEM_FILE" "$EC2_HOST" "tail -50 /home/ubuntu/app.log"
    exit 1
fi
```

### 스크립트 실행 권한 설정

```bash
chmod +x parantier-front/deploy.sh
chmod +x parantier-api/deploy.sh
```
