## 백엔드 배포

```bash

./gradlew clean bootJar
scp -i "/Users/terecal/dxline-container/hibot-d-server-key 복사본.pem" \
    build/libs/parantier-api-0.0.1-SNAPSHOT.jar \
    ubuntu@43.200.241.26:/home/ubuntu/
```

### 2. 서버에서 재시작

```bash
ssh -i "/Users/terecal/dxline-container/hibot-d-server-key 복사본.pem" ubuntu@43.200.241.26

# 기존 프로세스 종료

    --spring.profiles.active=prod \
```
