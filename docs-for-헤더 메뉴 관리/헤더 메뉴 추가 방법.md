# 헤더 메뉴 추가 방법 가이드

Palantier 프로젝트에서 상단 헤더에 새로운 메뉴를 추가하는 방법을 설명합니다.

## 1. 개요
헤더 메뉴는 데이터베이스의 `menus` 테이블에서 관리되며, 프론트엔드(`Header.tsx`)에서 `menu_type`이 `HEADER`이고 `parent_id`가 `NULL`인 항목을 조회하여 표시합니다.

## 2. 방법 1: 관리자 UI를 통한 추가 (권장)

관리자 계정으로 로그인한 후 아래 단계를 따르세요.

1.  **메뉴 관리 페이지 접속**: `http://localhost:5173/admin/menus`
2.  **새 메뉴 추가**:
    *   상단의 `+` 버튼을 클릭합니다.
    *   **메뉴 이름**: 헤더에 표시될 이름을 입력합니다. (예: `공지사항`)
    *   **메뉴 타입**: `HEADER`를 선택합니다.
    *   **경로 (Path)**: 클릭 시 이동할 경로를 입력합니다. (예: `/notice`)
    *   **정렬 순서**: 헤더에서 표시될 순서를 숫자로 입력합니다. (작을수록 왼쪽)
    *   **권한**: 필요한 경우 `ROLE_USER` 또는 `ROLE_ADMIN`을 선택합니다. (비워두면 누구나 접근 가능)
    *   **아이콘**: (선택) Lucide 아이콘 이름을 입력합니다.
3.  **저장**: `저장` 버튼을 클릭하면 즉시 헤더에 반영됩니다.

### 드롭다운 메뉴(하위 메뉴)를 만들고 싶은 경우
1.  위에서 만든 `HEADER` 메뉴를 선택합니다.
2.  우클릭 또는 하단 버튼을 통해 `하위 메뉴 추가`를 클릭합니다.
3.  하위 메뉴는 **메뉴 타입**을 `SUB`으로 설정하고 경로를 입력하면, 상위 `HEADER` 메뉴 클릭 시 드롭다운으로 나타납니다.

## 3. 방법 2: SQL을 통한 직접 추가

데이터베이스에 직접 쿼리를 실행하여 추가할 수 있습니다.

### 최상위 헤더 메뉴 추가 (링크형)
```sql
INSERT INTO menus (name, path, menu_type, order_num, required_role, icon)
VALUES ('관리 도구', '/tools', 'HEADER', 10, 'ROLE_ADMIN', 'Wrench');
```

### 드롭다운형 헤더 메뉴 및 하위 메뉴 추가
```sql
-- 1. 상위 헤더 메뉴 추가
INSERT INTO menus (name, menu_type, order_num, icon)
VALUES ('커뮤니티', 'HEADER', 20, 'Users')
RETURNING id; -- 여기서 생성된 ID를 확인 (예: 100)

-- 2. 하위 메뉴(드롭다운 항목) 추가
INSERT INTO menus (name, path, parent_id, menu_type, order_num)
VALUES ('자유게시판', '/community/free', 100, 'SUB', 1);
INSERT INTO menus (name, path, parent_id, menu_type, order_num)
VALUES ('Q&A', '/community/qna', 100, 'SUB', 2);
```

## 4. 프론트엔드 연동 확인

### 라우트 등록
메뉴를 추가했더라도 실제 페이지를 보려면 `parantier-front/src/app/routes/index.tsx` (또는 해당 라우터 설정 파일)에 경로가 등록되어 있어야 합니다.

### Header 컴포넌트 로직
헤더 메뉴는 `src/widgets/header/Header.tsx`에서 `useMenuTree` 훅을 통해 데이터를 가져오며, 아래와 같은 필터링 과정을 거칩니다.

```tsx
const headerMenus = menus
  .filter((menu) => menu.parentId === null && menu.menuType === "HEADER")
  // ... 권한 필터링 및 하위 메뉴 매핑
```

## 5. 주의사항
*   **캐시**: 메뉴 데이터는 React Query에 의해 약 30초간 캐싱됩니다. 즉시 반영이 안 될 경우 새로고침을 하거나 캐시 만료를 기다려주세요.
*   **경로**: 메뉴의 `path`는 라우터의 설정과 대소문자까지 정확히 일치해야 합니다.
