# 프론트엔드 컴포넌트 설계

## 📐 전체 구조

### 페이지 라우팅
```
/notes → NotesPage (노트 관리 메인 페이지)
```

**역할**:

- 상태 관리 (선택된 카테고리, 선택된 노트)

**상태**:
```typescript
const [selectedCategoryId, setSelectedCategoryId] = useState<number | null>(null)
const [selectedNoteId, setSelectedNoteId] = useState<number | null>(null)
```

**레이아웃**:
```tsx
<div className="flex h-[calc(100vh-64px)]">

    noteId={selectedNoteId}

  />
</div>
```

### 2. CategorySidebar (카테고리 트리)

**파일**: `parantier-front/src/features/note/components/CategorySidebar.tsx`

**역할**:
- 계층적 카테고리 트리 렌더링
- 아코디언 방식 접기/펼치기
- 선택된 카테고리 하이라이트

**Props**:
```typescript
interface CategorySidebarProps {
  selectedId: number | null
  onSelect: (id: number) => void
}
```

**주요 기능**:
- 재귀 컴포넌트로 트리 구조 렌더링
- shadcn/ui `Accordion` 사용
- 아이콘 + 카테고리명 표시

**구현 예시**:
```tsx
export function CategorySidebar({ selectedId, onSelect }: CategorySidebarProps) {
  const { data: categories = [] } = useNoteCategoryTree()

  return (
    <aside className="w-60 border-r bg-card overflow-y-auto">
      <div className="p-4">
        <h2 className="text-lg font-semibold mb-4">카테고리</h2>
        <CategoryTree
          categories={categories}
          selectedId={selectedId}
          onSelect={onSelect}
        />
      </div>
    </aside>
  )
}

// 재귀 트리 컴포넌트
function CategoryTree({ categories, selectedId, onSelect, depth = 0 }: TreeProps) {
  return (
    <div className={cn("space-y-1", depth > 0 && "ml-4")}>
      {categories.map((category) => (
        <div key={category.id}>
          <button
            onClick={() => onSelect(category.id)}
            className={cn(
              "w-full text-left px-3 py-2 rounded-md text-sm",
              selectedId === category.id
                ? "bg-primary text-primary-foreground"
                : "hover:bg-accent"
            )}
          >
            {category.icon && <span className="mr-2">{category.icon}</span>}
            {category.name}
          </button>

          {category.children && category.children.length > 0 && (
            <CategoryTree
              categories={category.children}
              selectedId={selectedId}
              onSelect={onSelect}
              depth={depth + 1}
            />
          )}
        </div>
      ))}
    </div>
  )
}
```

### 3. NoteList (노트 목록)

**파일**: `parantier-front/src/features/note/components/NoteList.tsx`

**역할**:
- 선택된 카테고리의 노트 목록 표시
- 검색 필터
- 새 노트 추가 버튼

**Props**:
```typescript
interface NoteListProps {
  categoryId: number | null
  selectedNoteId: number | null
  onSelectNote: (id: number) => void
}
```

**주요 기능**:
- 노트 제목, 작성자, 작성일 표시
- 상단 고정 노트 (📌 아이콘)
- 검색 입력 필드

**구현 예시**:
```tsx
export function NoteList({ categoryId, selectedNoteId, onSelectNote }: NoteListProps) {
  const [searchKeyword, setSearchKeyword] = useState('')

  const { data: notes = [] } = useNotes({
    categoryId,
    keyword: searchKeyword || undefined,
  })

  if (!categoryId) {
    return (
      <div className="flex-1 flex items-center justify-center text-muted-foreground">
        좌측에서 카테고리를 선택하세요
      </div>
    )
  }

  return (
    <div className="w-2/5 border-r flex flex-col">
      {/* 검색 & 추가 버튼 */}
      <div className="p-4 border-b space-y-2">
        <div className="flex gap-2">
          <Input
            placeholder="노트 검색..."
            value={searchKeyword}
            onChange={(e) => setSearchKeyword(e.target.value)}
            className="flex-1"
          />
          <Button onClick={() => handleNewNote()}>
            <Plus className="w-4 h-4 mr-1" />
            새 노트
          </Button>
        </div>
      </div>

      {/* 노트 목록 */}
      <div className="flex-1 overflow-y-auto">
        {notes.map((note) => (
          <div
            key={note.id}
            onClick={() => onSelectNote(note.id)}
            className={cn(
              "p-4 border-b cursor-pointer hover:bg-accent",
              selectedNoteId === note.id && "bg-accent"
            )}
          >
            <div className="flex items-center gap-2 mb-1">
              {note.isPinned && <span>📌</span>}
              <h3 className="font-semibold text-sm">{note.title}</h3>
            </div>
            <div className="text-xs text-muted-foreground">
              {note.authorName} · {formatDate(note.createdAt)} · 조회 {note.viewCount}
            </div>
          </div>
        ))}
      </div>
    </div>
  )
}
```

### 4. NoteEditor (에디터/뷰어)

**파일**: `parantier-front/src/features/note/components/NoteEditor.tsx`

**역할**:
- 읽기 모드: Markdown 렌더링
- 편집 모드: Markdown 에디터

**Props**:
```typescript
interface NoteEditorProps {
  noteId: number | null
  isEditing: boolean
  onToggleEdit: (editing: boolean) => void
}
```

**주요 기능**:
- Markdown 프리뷰 (`react-markdown`)
- 코드 블록 syntax highlighting (`react-syntax-highlighter`)
- 이미지 드래그앤드롭 업로드
- 저장/취소 버튼

**구현 예시**:
```tsx
import ReactMarkdown from 'react-markdown'
import { Prism as SyntaxHighlighter } from 'react-syntax-highlighter'
import { vscDarkPlus } from 'react-syntax-highlighter/dist/esm/styles/prism'

export function NoteEditor({ noteId, isEditing, onToggleEdit }: NoteEditorProps) {
  const { data: note } = useNote(noteId, { enabled: !!noteId })
  const [content, setContent] = useState('')

  useEffect(() => {
    if (note) setContent(note.content)
  }, [note])

  if (!noteId || !note) {
    return (
      <div className="flex-1 flex items-center justify-center text-muted-foreground">
        좌측에서 노트를 선택하세요
      </div>
    )
  }

  return (
    <div className="flex-1 flex flex-col">
      {/* 헤더 */}
      <div className="p-4 border-b flex justify-between items-center">
        <h1 className="text-2xl font-bold">{note.title}</h1>
        <div className="flex gap-2">
          {isEditing ? (
            <>
              <Button onClick={handleSave}>저장</Button>
              <Button variant="outline" onClick={() => onToggleEdit(false)}>
                취소
              </Button>
            </>
          ) : (
            <Button onClick={() => onToggleEdit(true)}>
              <Edit2 className="w-4 h-4 mr-1" />
              편집
            </Button>
          )}
        </div>
      </div>

      {/* 본문 */}
      <div className="flex-1 overflow-y-auto p-6">
        {isEditing ? (
          <textarea
            value={content}
            onChange={(e) => setContent(e.target.value)}
            className="w-full h-full border rounded-md p-4 font-mono text-sm"
          />
        ) : (
          <ReactMarkdown
            components={{
              code({ node, inline, className, children, ...props }) {
                const match = /language-(\w+)/.exec(className || '')
                return !inline && match ? (
                  <SyntaxHighlighter
                    style={vscDarkPlus}
                    language={match[1]}
                    PreTag="div"
                    {...props}
                  >
                    {String(children).replace(/\n$/, '')}
                  </SyntaxHighlighter>
                ) : (
                  <code className={className} {...props}>
                    {children}
                  </code>
                )
              },
            }}
          >
            {content}
          </ReactMarkdown>
        )}
      </div>
    </div>
  )
}
```

## 🔄 데이터 페칭 Hooks

### useNoteCategoryTree
```typescript
// parantier-front/src/features/note/hooks/useNoteCategoryTree.ts
export function useNoteCategoryTree() {
  return useQuery({
    queryKey: ['note-categories'],
    queryFn: async () => {
      const { data } = await apiClient.get('/note-categories')
      return data
    },
  })
}
```

### useNotes
```typescript
export function useNotes(params: { categoryId?: number; keyword?: string }) {
  return useQuery({
    queryKey: ['notes', params],
    queryFn: async () => {
      const { data } = await apiClient.get('/notes', { params })
      return data.content
    },
    enabled: !!params.categoryId,
  })
}
```

### useNote
```typescript
export function useNote(noteId: number | null, options = {}) {
  return useQuery({
    queryKey: ['notes', noteId],
    queryFn: async () => {
      const { data } = await apiClient.get(`/notes/${noteId}`)
      return data
    },
    ...options,
  })
}
```

### useCreateNote, useUpdateNote, useDeleteNote
```typescript
export function useCreateNote() {
  const queryClient = useQueryClient()
  return useMutation({
    mutationFn: async (request: CreateNoteRequest) => {
      const { data } = await apiClient.post('/notes', request)
      return data
    },
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['notes'] })
      toast.success('노트가 생성되었습니다')
    },
  })
}
```
