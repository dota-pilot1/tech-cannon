# 노트 관리 기능 구현 계획

## 📌 프로젝트 개요

### 목적
- 개발 지식을 체계적으로 정리하고 관리할 수 있는 노트 시스템 구현
- 기존의 메뉴 기반 접근 방식 대신, 계층적 카테고리 구조로 효율적인 정보 탐색 제공

### 기존 문제점
❌ **현재 방식**: 각 주제별로 별도 메뉴 생성 (Frontend Note, Backend Note, ...)
- 메뉴가 너무 많아짐
- 계층 관리 어려움
- 확장성 부족

✅ **개선 방향**: 단일 "노트 관리" 페이지 내에서 모든 노트를 계층적으로 관리
- 카테고리 트리로 체계적 분류
- 3단 레이아웃으로 직관적인 탐색
- 확장 가능한 구조

---

## 🎯 핵심 기능

### 1. 계층적 카테고리 시스템
- **대분류 (Level 1)**: Core, Client/UX, Server/API, Infra 확장, 시스템/확장
- **중분류 (Level 2)**: Frontend, Backend, Database, Design, State Management 등
- **무제한 depth 지원**: 필요시 3단계 이상도 가능

### 2. 3단 레이아웃
```
┌──────────────┬───────────────────┬─────────────────────────┐
│  좌측         │  중앙              │  우측                    │
│  카테고리 트리│  노트 주제 목록    │  노트 본문 & 에디터      │
│  (240px)     │  (flex 40%)       │  (flex 60%)             │
└──────────────┴───────────────────┴─────────────────────────┘
```

#### 좌측: 카테고리 트리
- 아코디언 방식 접기/펼치기
- 아이콘 + 카테고리명
- 선택된 카테고리 하이라이트

#### 중앙: 노트 주제 목록
- 선택된 카테고리의 노트 리스트
- 제목, 작성자, 작성일, 조회수
- 상단 고정 기능 (is_pinned)
- 검색 필터

#### 우측: 노트 본문 & 에디터
- Markdown 에디터
- 코드 블록 syntax highlighting
- 이미지 첨부 (드래그앤드롭)
- 저장/수정/삭제 버튼

### 3. Markdown 에디터
- **라이브러리 후보**:
  - `react-markdown` + `react-syntax-highlighter` (가벼움)
  - `@toast-ui/react-editor` (기능 풍부)
  - `@uiw/react-md-editor` (간단함)

### 4. 권한 관리
- **is_public**: true면 전체 공개, false면 작성자만 조회
- 작성자만 수정/삭제 가능
- 관리자는 모든 노트 관리 가능

### 5. 추가 기능
- 전체 텍스트 검색 (제목 + 본문)
- 태그 기반 필터링
- 조회수 추적
- 노트 버전 히스토리 (선택사항)
- 북마크 기능 (선택사항)

## 🗂️ 데이터베이스 설계

### 주요 테이블
1. **note_categories**: 카테고리 계층 구조
2. **notes**: 노트 본문 및 메타데이터
3. **note_attachments**: 첨부파일 관리
4. **note_versions**: 버전 히스토리 (선택)

자세한 스키마는 `테이블 설계/` 폴더 참조

## 🎨 UI/UX 설계

### 화면 흐름
1. 사용자가 "노트 관리" 메뉴 클릭
2. 좌측에 카테고리 트리 표시
3. 카테고리 선택 → 중앙에 해당 노트 목록 표시
4. 노트 선택 → 우측에 본문 표시
5. 편집 모드 전환 → Markdown 에디터로 수정
6. 저장 → 서버에 업데이트

### 주요 인터랙션
- 카테고리 클릭: 해당 노트 목록 로드
- 노트 클릭: 본문 표시 (조회수 +1)
- 편집 버튼: 에디터 모드 전환
- 새 노트 추가: 중앙 상단 "+" 버튼
- 드래그앤드롭: 이미지 첨부

상세 UI 흐름은 `uiux 흐름 mmd/` 폴더의 Mermaid 다이어그램 참조

## 📦 기술 스택

### Frontend
- React 19 + TypeScript
- TanStack Router (라우팅)
- TanStack Query (데이터 페칭)
- Tailwind CSS + shadcn/ui (UI 컴포넌트)
- Markdown 에디터 라이브러리 (TBD)

### Backend
- Spring Boot 3 + MyBatis
- PostgreSQL (계층 쿼리 지원)
- AWS S3 (이미지 첨부파일 저장)
