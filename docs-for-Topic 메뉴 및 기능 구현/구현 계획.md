# Topic 메뉴 및 기능 구현 계획

## 1. 개요

뉴스/기사/유튜브 링크 등을 공유하고 토론하는 Topic 게시판.
- **좌측**: ag-grid 목록 (제목, 작성자, 날짜 등)
- **우측**: 상세 보기 + 댓글 (FullscreenDialogContent 또는 split-panel)
- **에디터**: Lexical 기반, 링크 미리보기(YouTube embed, OG meta) 지원
- **검색**: title + content 통합 검색
- **딥링크**: `?topicId=123` 쿼리 파라미터로 특정 Topic 바로 접근

## 2. DB 테이블 설계

### topics 테이블
```sql
CREATE TABLE topics (
    id BIGSERIAL PRIMARY KEY,
    title VARCHAR(500) NOT NULL,
    content TEXT,                        -- Lexical JSON state
    content_plain TEXT,                  -- 검색용 plain text (title+content 통합검색)
    author_id BIGINT NOT NULL REFERENCES users(id),
    author_name VARCHAR(100) NOT NULL,
    view_count INT DEFAULT 0,
    comment_count INT DEFAULT 0,        -- 댓글 수 캐시
    is_pinned BOOLEAN DEFAULT FALSE,    -- 상단 고정
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_topics_author_id ON topics(author_id);
CREATE INDEX idx_topics_created_at ON topics(created_at DESC);
CREATE INDEX idx_topics_search ON topics USING gin(to_tsvector('simple', coalesce(title,'') || ' ' || coalesce(content_plain,'')));
```

### topic_comments 테이블
```sql
CREATE TABLE topic_comments (
    id BIGSERIAL PRIMARY KEY,
    topic_id BIGINT NOT NULL REFERENCES topics(id) ON DELETE CASCADE,
    author_id BIGINT NOT NULL REFERENCES users(id),
    author_name VARCHAR(100) NOT NULL,
    content TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_topic_comments_topic_id ON topic_comments(topic_id);
```

> **참고**: `content_plain`은 Lexical JSON에서 텍스트만 추출한 값. 백엔드에서 저장 시 자동 생성.

### API 엔드포인트

| Method | Path | 설명 |
|--------|------|------|
| GET | `/api/topics` | 목록 조회 (페이징, 검색) |
| GET | `/api/topics/{id}` | 상세 조회 (조회수 +1) |
| POST | `/api/topics` | 생성 |
| PUT | `/api/topics/{id}` | 수정 |
| DELETE | `/api/topics/{id}` | 삭제 |
| GET | `/api/topics/{topicId}/comments` | 댓글 목록 |
| POST | `/api/topics/{topicId}/comments` | 댓글 작성 |
| DELETE | `/api/topics/{topicId}/comments/{id}` | 댓글 삭제 |

### 검색 API
```
GET /api/topics?keyword=검색어&page=0&size=20
```
- `keyword`가 있으면 `title ILIKE '%keyword%' OR content_plain ILIKE '%keyword%'` 필터
- 데이터 소량이면 ILIKE로 충분, 대량 시 PostgreSQL full-text search 전환 가능

### 4-3. Lexical 에디터 확장 (뉴스/링크 + 이미지)

기존 `shared/ui/lexical/LexicalEditor`에 플러그인/노드를 추가하여 공용으로 강화.
(Topic 전용이 아니라 shared 레벨에서 확장 → 다른 페이지에서도 재사용 가능)

#### A. 이미지 업로드/편집 기능

**현재 상태**: Lexical 에디터에 이미지 관련 기능 전혀 없음 (ImageNode, 플러그인 모두 없음)

**업로드 방식**: 기존 Presigned URL 패턴 활용 (`UploadController` + `S3Service`)
- Work/Issue 이미지 업로드와 동일한 흐름: 프론트에서 presigned URL 요청 → S3에 직접 PUT → 반환된 URL을 에디터에 삽입

**구현 파일 구조:**
```
shared/ui/lexical/
├── nodes/
│   └── ImageNode.tsx              -- 커스텀 ImageNode (DecoratorNode 상속)
├── plugins/
│   ├── ImagePlugin.tsx            -- 이미지 삽입 커맨드 핸들러
│   ├── DragDropImagePlugin.tsx    -- 드래그앤드롭 + 클립보드 붙여넣기 지원
│   └── ImageResizePlugin.tsx      -- 이미지 크기 조절 핸들
├── components/
│   └── ImageComponent.tsx         -- 이미지 렌더링 컴포넌트 (리사이즈 핸들 포함)
└── toolbar/
    └── ImageButton.tsx            -- 툴바 이미지 삽입 버튼
```

**ImageNode 설계:**
```typescript
// DecoratorNode를 상속한 커스텀 노드
class ImageNode extends DecoratorNode<JSX.Element> {
  __src: string        // S3 URL
  __altText: string
  __width: number | 'inherit'
  __height: number | 'inherit'
  __alignment: 'left' | 'center' | 'right'  // 위치 정렬

  // JSON 직렬화/역직렬화 (Lexical state 저장용)
  static importJSON(json): ImageNode
  exportJSON(): SerializedImageNode

  // DOM export (LexicalViewer HTML 렌더링용)
  exportDOM(): DOMExportOutput
  static importDOM(): DOMConversionMap
}
```

**이미지 삽입 방법 (3가지):**
1. **툴바 버튼** — 파일 선택 다이얼로그 → S3 업로드 → 노드 삽입
2. **드래그앤드롭** — 파일을 에디터 영역에 드롭 → S3 업로드 → 노드 삽입
3. **클립보드 붙여넣기** — Ctrl+V 이미지 → S3 업로드 → 노드 삽입

**이미지 크기 조절:**
- 이미지 클릭 시 선택 상태 → 모서리에 리사이즈 핸들 표시
- 마우스 드래그로 크기 조절 → `width`/`height` 업데이트
- 비율 유지 옵션 (Shift 키)

**이미지 위치/정렬:**
- 이미지 선택 시 플로팅 툴바 표시: [왼쪽 | 가운데 | 오른쪽]
- `alignment` 속성으로 CSS `text-align` / `float` 제어

**업로드 흐름 (Presigned URL 패턴 참고):**
```
1. 프론트: POST /api/upload/presign { filename, contentType }
2. 백엔드: S3Service.createPresignedPutUrl() → presigned URL 반환
3. 프론트: PUT presignedUrl (파일 직접 업로드)
4. 프론트: S3 URL을 ImageNode에 설정하여 에디터에 삽입
```

> **참고 파일**: `upload/presentation/UploadController.java`, `upload/application/S3Service.java`, `api/profileApi.ts`

**LexicalViewer 업데이트:**
- `ImageNode`를 노드 목록에 등록해야 JSON → HTML 변환 시 이미지 렌더링 가능
- `exportDOM()`에서 `<img>` 태그 + 인라인 스타일(width, height, alignment) 생성

#### B. 링크/영상 편의 기능

**추가 기능:**
1. **AutoLinkPlugin** — URL 자동 감지 및 링크 변환 (Lexical 내장 플러그인)
2. **YouTubeNode** — YouTube URL 붙여넣기 시 embed 자동 변환
3. **LinkPreviewNode** (선택) — OG 메타 기반 링크 카드 미리보기

**구현 우선순위:**
- Phase 1: AutoLinkPlugin + YouTube embed (핵심)
- Phase 2: OG meta 링크 카드 (나중에 필요 시)
